# ✨ الميزات الجديدة المضافة - الإضبارات والعلاقات

## 🆕 ما تم إضافته

### 1. نظام الإضبارات (Folders) 📁

**الوصف:** نظام كامل لتنظيم المستندات في إضبارات (مجلدات منطقية)

**المميزات:**
- ✅ إنشاء إضبارات حسب النوع (مشروع، عميل، شحنة، عقد، قضية، موظف)
- ✅ إضافة مستندات متعددة لإضبارة واحدة
- ✅ إضبارات هرمية (إضبارة داخل إضبارة)
- ✅ كل إضبارة لها كود فريد
- ✅ إحصائيات لكل إضبارة
- ✅ ربط بقسم محدد

**حالات استخدام:**
```
مثال 1: شحنة كاملة
- إضبارة: "شحنة ديسمبر 2025 - حاوية 001"
- تحتوي: 12 مستند (أمر شراء، بوليصة، فاتورة، جمارك، فحص...)
- الفائدة: الوصول السريع لجميع مستندات الشحنة

مثال 2: مشروع توسعة
- إضبارة: "مشروع توسعة المستودع"
- تحتوي: 28 مستند (عقود، فواتير، تقارير، رخص)
- الفائدة: ملف كامل للمشروع

مثال 3: ملف عميل
- إضبارة: "عميل ABC Trading"
- تحتوي: 45 مستند (عقود، فواتير، مراسلات)
- الفائدة: تاريخ كامل للتعامل مع العميل
```

---

### 2. علاقات المستندات (Document Relations) 🔗

**الوصف:** نظام لربط المستندات ببعضها البعض

**أنواع العلاقات:**
1. **مستند أصلي/فرعي (Parent/Child)**
   - للهرمية (عقد رئيسي → ملاحق)
   
2. **مرجع (Reference)**
   - مستندات مرجعية لبعضها
   
3. **بديل (Replacement)**
   - عند استبدال مستند بآخر
   
4. **تعديل (Amendment)**
   - للتعديلات والملاحق
   
5. **ذو صلة (Related)**
   - مستندات مرتبطة عامة

**مثال واقعي:**
```
شحنة حاوية MSCU7832651:
  ← أمر الشراء (PO-2025-1234) [علاقة: مرجع]
  ← بوليصة الشحن (NBS-SC-00847) [المستند الرئيسي]
  → الفاتورة (INV-2025-5678) [علاقة: ذو صلة]
  → تقرير الجودة (QC-2025-456) [علاقة: ذو صلة]
  → البيان الجمركي (CUSTOMS-789) [علاقة: ذو صلة]
  → إيصال الاستلام (REC-2025-321) [علاقة: ذو صلة]
```

---

### 3. المرفقات (Attachments) 📎

**الوصف:** إضافة ملفات داعمة لأي مستند

**المميزات:**
- ✅ مرفقات غير محدودة لكل مستند
- ✅ أنواع مرفقات (داعم، مرجع، إثبات، صورة)
- ✅ جميع أنواع الملفات مدعومة
- ✅ تحميل منفصل لكل مرفق
- ✅ عداد المرفقات على بطاقة المستند

**أنواع المرفقات:**
1. **مستند داعم (Supporting)** - مستندات إضافية
2. **مرجع (Reference)** - مراجع وإثباتات
3. **إثبات (Proof)** - مستندات إثبات
4. **صورة (Image)** - صور توضيحية
5. **أخرى (Other)** - أي نوع آخر

**مثال:**
```
بوليصة الشحن NBS-SC-00847:
  + صورة من جواز السفر البحري (PDF, 2.4 MB)
  + صورة الحاوية من الميناء (JPG, 1.8 MB)
  + كشف البضائع التفصيلي (XLSX, 856 KB)
  + خطاب الشحن من المورد (DOCX, 124 KB)
```

## 📊 Database Models المُنشأة

### 1. `nbs.document.folder`
```python
- name: اسم الإضبارة
- code: رمز فريد
- department_id: القسم
- folder_type: نوع الإضبارة
- document_ids: المستندات (Many2many)
- parent_folder_id: الإضبارة الأم
- child_folder_ids: إضبارات فرعية
- state: الحالة
```

### 2. `nbs.document.relation`
```python
- document_id: المستند الأول
- related_document_id: المستند الثاني
- relation_type: نوع العلاقة
- notes: ملاحظات
```

### 3. `nbs.document.attachment`
```python
- document_id: المستند الأصلي
- name: اسم المرفق
- file_data: الملف
- file_name: اسم الملف
- file_size: الحجم
- attachment_type: نوع المرفق
- uploader_id: الرافع
```

## 🎯 API Endpoints الجديدة

### Folders:
```javascript
POST /api/folders                    // قائمة الإضبارات
POST /api/folders/create             // إنشاء إضبارة
POST /api/folders/{id}/documents     // مستندات الإضبارة
POST /api/folders/{id}/add-document  // إضافة مستند للإضبارة
```

### Relations:
```javascript
POST /api/documents/{id}/relations           // جميع العلاقات
POST /api/documents/{id}/add-relation        // إضافة علاقة
```

### Attachments:
```javascript
POST /api/documents/{id}/attachments         // جميع المرفقات
POST /api/documents/{id}/add-attachment      // إضافة مرفق
GET  /api/documents/{id}/attachments/{att_id}/download  // تحميل مرفق
```
