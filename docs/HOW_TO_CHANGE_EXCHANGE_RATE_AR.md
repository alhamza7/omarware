# 💱 كيفية تغيير معامل التحويل للدينار العراقي

**التاريخ:** 2026-01-11  
**الموضوع:** تغيير سعر الصرف USD إلى IQD

---

## 📋 نظرة عامة

سعر الصرف (Exchange Rate) يُستخدم لتحويل المبالغ من الدولار الأمريكي (USD) إلى الدينار العراقي (IQD).

**القيمة الافتراضية الحالية:** 1,300 IQD = 1 USD

---

## 🎯 طرق تغيير سعر الصرف

### الطريقة 1: تغيير سعر الصرف لطلب واحد (من Backend)

#### الخطوات:
1. افتح Odoo → **POS Perfume** → **Backend Orders**
2. افتح الطلب الذي تريد تعديله
3. ابحث عن حقل **"Exchange Rate (USD to IQD)"** أو **"سعر الصرف"**
4. غيّر القيمة (مثال: 1310، 1320، إلخ)
5. اضغط **Save** (حفظ)

✅ **النتيجة:** سيتم إعادة حساب المجموع بالدينار تلقائياً

**مثال:**
```
السعر القديم: 1,300 IQD/USD
المجموع: $100 → 130,000 IQD

السعر الجديد: 1,320 IQD/USD
المجموع: $100 → 132,000 IQD
```

---

### الطريقة 2: تغيير القيمة الافتراضية للطلبات الجديدة

هذه الطريقة تغيّر السعر الافتراضي لجميع الطلبات الجديدة.

#### الخطوات:

1. **افتح ملف الموديل:**
```
addons/pos_perfume_custom/models/pos_perfume_order.py
```

2. **ابحث عن السطر 137-141:**
```python
exchange_rate = fields.Float(
    string='Exchange Rate (USD to IQD)',
    default=1300.0,  # ← هنا
    digits=(12, 2)
)
```

3. **غيّر القيمة الافتراضية:**
```python
exchange_rate = fields.Float(
    string='Exchange Rate (USD to IQD)',
    default=1320.0,  # ← القيمة الجديدة
    digits=(12, 2)
)
```

4. **احفظ الملف**

5. **أعد تشغيل Odoo:**
```bash
# على الخادم
sudo systemctl restart odoo
```

6. **حدّث الوحدة:**
- Apps → Developer Mode
- ابحث: `POS Perfume Custom`
- اضغط **Upgrade**

✅ **النتيجة:** جميع الطلبات الجديدة ستستخدم السعر الجديد تلقائياً

⚠️ **ملاحظة:** الطلبات القديمة لن تتأثر، فقط الطلبات الجديدة!

---

### الطريقة 3: تغيير سعر الصرف من POS مباشرة

حالياً، POS Perfume **لا يسمح** بتعديل سعر الصرف من الواجهة. ولكن يمكنك إضافة هذه الميزة:

#### إضافة حقل سعر الصرف في POS:

دعني أضيف هذه الميزة لك! سأحتاج إلى:

1. إضافة حقل في الواجهة
2. السماح بتعديله
3. حفظه مع الطلب

**هل تريد مني إضافة هذه الميزة؟** إذا نعم، سأقوم بذلك الآن! ✨

## 🔄 كيف يتم الحساب؟

### المعادلة:
```
المبلغ بالدينار = المبلغ بالدولار × سعر الصرف
```

### مثال 1:
```
المجموع: $100
سعر الصرف: 1,300
النتيجة: 100 × 1,300 = 130,000 IQD
```

### مثال 2:
```
المجموع: $250.50
سعر الصرف: 1,320
النتيجة: 250.50 × 1,320 = 330,660 IQD
```

## 🛠️ أماكن سعر الصرف في الكود

### 1. الموديل الرئيسي:
```python
# addons/pos_perfume_custom/models/pos_perfume_order.py
exchange_rate = fields.Float(
    string='Exchange Rate (USD to IQD)',
    default=1300.0,
    digits=(12, 2)
)
```

### 2. حساب المجموع بالدينار:
```python
@api.depends('amount_total', 'exchange_rate')
def _compute_amount_iqd(self):
    for order in self:
        order.amount_total_iqd = order.amount_total * order.exchange_rate
```

### 3. في التقرير:
```xml
<span t-field="o.exchange_rate"/> د.ع
```

### تغيير سعر صرف المنتجات:

إذا كنت تريد تغيير سعر الصرف المستخدم في عرض أسعار المنتجات بالدينار:

```python
def _compute_price_iqd(self):
    exchange_rate = 1300.0  # ← غيّر هنا
    for product in self:
        product.price_iqd = product.list_price * exchange_rate
```

## 📝 أسئلة شائعة

### س1: هل يمكن أن يكون سعر الصرف مختلف لكل طلب؟
**ج:** نعم! كل طلب له سعر صرف خاص به يمكن تعديله.

### س2: ماذا يحدث للطلبات القديمة عند تغيير السعر الافتراضي؟
**ج:** لا شيء. الطلبات القديمة تحتفظ بسعر الصرف الذي تم استخدامه عند إنشائها.

### س3: هل يمكن جعل سعر الصرف يتحدث تلقائياً من مصدر خارجي؟
**ج:** نعم! يمكن ربطه بـ API خارجي لتحديث السعر تلقائياً. هل تريد هذه الميزة؟

### س4: كيف أعرف سعر الصرف المستخدم في طلب قديم؟
**ج:** افتح الطلب من Backend Orders، سيظهر في حقل "Exchange Rate"

### س5: هل سعر الصرف يُرسل إلى SAP؟
**ج:** نعم، يُحفظ مع الطلب ويمكن إرساله إلى SAP إذا كان معدّاً.

## 🆘 حل المشاكل

### المشكلة: المجموع بالدينار خاطئ
**الحل:**
1. تحقق من قيمة "Exchange Rate" في الطلب
2. تأكد من أنها الرقم الصحيح
3. احفظ الطلب مرة أخرى لإعادة الحساب

### المشكلة: لا أستطيع تغيير سعر الصرف
**الحل:**
1. تأكد من أنك في وضع التعديل (Edit Mode)
2. تحقق من صلاحياتك
3. الطلبات المؤكدة قد لا تسمح بالتعديل

### المشكلة: التغيير لا يظهر في الطلبات الجديدة
**الحل:**
1. تأكد من حفظ الملف
2. أعد تشغيل Odoo
3. حدّث الوحدة من Apps
