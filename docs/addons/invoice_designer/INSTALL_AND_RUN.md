## خطوات التثبيت

### الخطوة 1: تحديث الموديولات ⚙️

افتح PowerShell وشغّل:

```powershell
cd D:\capo_dev\Lugal-ai
.\venv\Scripts\python.exe odoo-bin -c odoo_simple.conf -d lugal -u invoice_designer,pos_perfume_custom
```

**انتظر حتى تكتمل العملية** (حوالي 2-3 دقائق)

### الخطوة 2: إعادة تشغيل Odoo 🔄

1. أوقف Odoo (Ctrl+C)
2. شغّله من جديد:

```powershell
.\venv\Scripts\python.exe odoo-bin -c odoo_simple.conf -d lugal
```

### الخطوة 3: تسجيل الدخول ✅

1. افتح المتصفح
2. اذهب إلى: `http://localhost:8070`
3. سجّل الدخول

## التجربة السريعة

### جرّب القوالب الجاهزة (دقيقة واحدة!)

```
1. POS Perfume → Orders
2. افتح أي طلب
3. اضغط "طباعة مع المصمم"
4. احصل على PDF! ✅
```

### افتح المصمم المرئي (5 دقائق)

```
1. POS Perfume → Orders
2. افتح طلب
3. اضغط "فتح المصمم"
4. استمتع بالتصميم! 🎨
```

### شاهد القوالب الجاهزة

```
Invoice Designer → Templates

ستجد قالبين:
✨ فاتورة POS Perfume - كلاسيكي (الافتراضي)
🎨 فاتورة POS Perfume - عصري
```

## الوظائف الأساسية

### في نموذج الطلب

| الزر | الوظيفة |
|------|---------|
| **طباعة مع المصمم** | PDF فوري باستخدام القالب |
| **فتح المصمم** | فتح المصمم للتخصيص |
| **قالب الفاتورة** | اختيار قالب مخصص |

### في المصمم

| الزر | الوظيفة |
|------|---------|
| ➕ **إضافة** | إضافة عنصر جديد |
| 💾 **حفظ** | حفظ التغييرات |
| 👁️ **معاينة** | معاينة PDF |
| 🗑️ **حذف** | حذف العنصر |
| ⬆️ **للأمام** | طبقة أمامية |
| ⬇️ **للخلف** | طبقة خلفية |

## أمثلة سريعة

### إضافة شعار جديد

```
1. افتح المصمم
2. "إضافة" → "صورة"
3. رفع الصورة
4. حفظ ✅
```

### تغيير لون العنوان

```
1. اختر العنوان
2. في اللوحة اليمنى: اللون
3. اختر اللون الجديد
4. حفظ ✅
```

### إضافة QR Code

```
1. "إضافة" → "QR Code"
2. حدد الموقع
3. حفظ ✅
```
