# 🎨 دليل مصمم الفواتير الشامل - Invoice Designer

## نظرة عامة

مصمم الفواتير هو أداة قوية وسهلة الاستخدام تتيح لك تصميم فواتير مخصصة بالكامل باستخدام واجهة سحب وإفلات (Drag & Drop) مرئية.

---

## ✨ المميزات الرئيسية

### 1. واجهة مرئية شاملة
- ✅ **Drag & Drop**: سحب وإفلات العناصر بسهولة
- ✅ **شبكة إرشادية**: لمحاذاة دقيقة للعناصر
- ✅ **Zoom In/Out**: تكبير/تصغير بنسبة 50% - 200%
- ✅ **Undo/Redo**: تراجع وإعادة (حتى 50 خطوة)
- ✅ **معاينة مباشرة**: رؤية التغييرات فوراً

### 2. أنواع العناصر (10 أنواع)
1. **نص ثابت** (Text): لعناوين وملاحظات ثابتة
2. **حقل ديناميكي** (Field): بيانات من النظام (اسم عميل، تاريخ، إلخ)
3. **صورة** (Image): شعارات وصور
4. **جدول** (Table): جدول المنتجات
5. **شكل** (Shape): مربعات، دوائر، مثلثات
6. **خط** (Line): خطوط فاصلة
7. **باركود** (Barcode): باركود للفاتورة
8. **QR Code**: رمز QR للفاتورة
9. **أيقونة** (Icon): أيقونات FontAwesome
10. **تدرج لوني** (Gradient Box): خلفيات بتدرجات جذابة

### 3. خصائص متقدمة للعناصر

#### خصائص الخطوط (Typography)
- **نوع الخط**: 9 خطوط (بما فيها خطوط عربية)
- **حجم الخط**: 6-100pt
- **وزن الخط**: 9 أوزان (100-900)
  - 100: Thin (رفيع)
  - 400: Normal (عادي)
  - 700: Bold (عريض)
  - 900: Black (أسود)
- **نمط الخط**: عادي، مائل، منحرف
- **محاذاة النص**: يسار، وسط، يمين، ضبط
- **تزيين النص**: تسطير، خط علوي، خط وسط
- **تحويل النص**: أحرف كبيرة، صغيرة، أول حرف كبير

#### خصائص الموقع والحجم
- **X, Y**: الموقع بالمليمتر (mm)
- **العرض والارتفاع**: الحجم بالمليمتر
- **الدوران**: 0-360 درجة
- **Z-Index**: ترتيب الطبقات

#### خصائص الألوان والنمط
- **لون النص/الحد**: منتقي ألوان + كود hex
- **لون الخلفية**: دعم الشفافية
- **عرض الحد**: 0-20px
- **نمط الحد**: صلب، متقطع، منقط، مزدوج
- **الشفافية**: 0-100%
- **نصف قطر الحواف**: حواف دائرية 0-100px

#### تأثيرات متقدمة
- **ظل (Shadow)**: `2px 2px 5px rgba(0,0,0,0.3)`
- **Padding**: مسافات داخلية
- **تباعد الأسطر**: 0.5-5

## 🚀 البدء السريع

### 1. فتح المصمم

#### من قائمة Invoice Designer:
```
الفواتير والمحاسبة → Invoice Designer → Templates → [اختر قالب] → زر "فتح المصمم"
```

#### من POS Perfume Order:
```
POS Perfume → Orders → [اختر طلب] → زر "فتح المصمم"
```

### 2. إنشاء قالب جديد

1. انتقل إلى: `Invoice Designer → Templates → Create`
2. املأ المعلومات:
   - **الاسم**: "فاتورة العطور الجديدة"
   - **الكود**: `perfume_invoice_2024`
   - **نوع المستند**: POS Receipt
   - **حجم الصفحة**: A4 (210 x 297 mm)
3. احفظ ثم اضغط "فتح المصمم"

## 🎯 إضافة العناصر - أمثلة عملية

### مثال 1: إضافة شعار الشركة

1. اضغط **"إضافة" → "صورة"**
2. من لوحة الخصائص اليمنى:
   - **الاسم**: "شعار الشركة"
   - **X**: 15mm
   - **Y**: 10mm
   - **العرض**: 50mm
   - **الارتفاع**: 30mm
3. في قسم "إعدادات الصورة":
   - **رفع صورة**: اختر ملف الشعار، أو
   - **رابط الصورة**: أدخل URL، أو
   - **حقل ديناميكي**: `company_id.logo`
   - **طريقة الملائمة**: احتواء (Contain)

### مثال 2: عنوان الفاتورة

1. اضغط **"إضافة" → "نص ثابت"**
2. الخصائص:
   - **النص**: "فــــاتــــورة"
   - **X**: 15mm, **Y**: 50mm
   - **العرض**: 180mm
   - **نوع الخط**: Arial
   - **حجم الخط**: 24pt
   - **وزن الخط**: 700 (Bold)
   - **محاذاة النص**: وسط (Center)
   - **اللون**: #1a1a1a

### مثال 3: رقم الفاتورة (ديناميكي)

1. اضغط **"إضافة" → "حقل ديناميكي"**
2. الخصائص:
   - **الاسم**: "رقم الفاتورة"
   - **اسم الحقل**: `name`
   - **X**: 15mm, **Y**: 68mm
   - **حجم الخط**: 12pt
   - **وزن الخط**: 600 (Semi Bold)

### مثال 4: خط فاصل أنيق

1. اضغط **"إضافة" → "خط"**
2. الخصائص:
   - **X**: 15mm, **Y**: 45mm
   - **العرض**: 180mm
   - **الارتفاع**: 1mm
   - **اللون**: #333333
   - **عرض الحد**: 2px

### مثال 5: مربع بتدرج لوني

1. اضغط **"إضافة" → "تدرج لوني"**
2. الخصائص:
   - **X**: 0mm, **Y**: 0mm
   - **العرض**: 210mm
   - **الارتفاع**: 60mm
   - **لون الخلفية**: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
   - **نصف قطر الحواف**: 0px

### مثال 6: جدول المنتجات

1. اضغط **"إضافة" → "جدول"**
2. الخصائص:
   - **اسم الحقل**: `order_line_ids`
   - **X**: 15mm, **Y**: 95mm
   - **العرض**: 180mm
   - **الارتفاع**: 120mm
   - **عرض الحد**: 1px
   - **نمط الحد**: صلب (Solid)
   - **لون الحد**: #dddddd

### مثال 7: QR Code للفاتورة

1. اضغط **"إضافة" → "QR Code"**
2. الخصائص:
   - **اسم الحقل**: `name`
   - **X**: 20mm, **Y**: 235mm
   - **العرض**: 35mm
   - **الارتفاع**: 35mm

## 📋 الحقول الديناميكية المتاحة

### معلومات الطلب (POS Perfume Order)
```
name                    # رقم الفاتورة

amount_subtotal         # المجموع الفرعي
amount_discount         # الخصم
amount_tax              # الضريبة
amount_total            # المجموع الكلي
amount_total_iqd        # المجموع بالدينار
exchange_rate           # سعر الصرف
note                    # الملاحظات
invoice_type            # نوع الفاتورة (1-8)
order_line_ids          # سطور الطلب (للجدول)
```

### معلومات الشركة
```
company_id.name         # اسم الشركة
company_id.logo         # شعار الشركة
company_id.street       # عنوان الشركة
company_id.phone        # هاتف الشركة
company_id.email        # بريد إلكتروني
company_id.website      # الموقع الإلكتروني
company_id.vat          # الرقم الضريبي
```

### صيغ العرض (Field Format)
```
للأرقام:
  %.2f                  # رقمين بعد الفاصلة (مثال: 123.45)
  %.0f                  # بدون كسور (مثال: 123)
  $%.2f                 # مع رمز الدولار ($123.45)

للتاريخ:
  %Y-%m-%d              # 2024-12-24
  %d/%m/%Y              # 24/12/2024
  %Y-%m-%d %H:%M        # 2024-12-24 14:30
  %d %B %Y              # 24 December 2024
```

## 🐛 حل المشاكل الشائعة

### المشكلة 1: العنصر لا يظهر
**الحل**:
- تحقق من Z-Index (قد يكون خلف عنصر آخر)
- تحقق من اللون (قد يكون نفس لون الخلفية)
- تحقق من الشفافية (Opacity)

### المشكلة 2: النص مقطوع
**الحل**:
- زِد عرض أو ارتفاع العنصر
- قلل حجم الخط
- استخدم Line Height أكبر

### المشكلة 3: الصورة لا تظهر
**الحل**:
- تحقق من رفع الصورة بشكل صحيح
- تحقق من URL الصورة
- استخدم Object Fit: Contain أو Cover

### المشكلة 4: الجدول فارغ
**الحل**:
- تحقق من **اسم الحقل**: يجب أن يكون `order_line_ids`
- تأكد من وجود سطور في الطلب

### المشكلة 5: الحقل الديناميكي لا يعمل
**الحل**:
- تحقق من اسم الحقل (Case Sensitive)
- استخدم النقطة للحقول المرتبطة: `partner_id.name`
- تحقق من صيغة العرض (Field Format)

## 🎓 أمثلة متقدمة

### مثال 1: فاتورة بخلفية صورة

```xml
<element>
  <name>خلفية</name>
  <type>image</type>
  <x>0</x>
  <y>0</y>
  <width>210</width>
  <height>297</height>
  <z_index>1</z_index>
  <opacity>0.1</opacity>  <!-- 10% شفافية -->
  <image_url>https://example.com/watermark.png</image_url>
</element>
```

### مثال 2: نص بظل ثلاثي الأبعاد

```css
Box Shadow: 3px 3px 0px rgba(0,0,0,0.2), 6px 6px 0px rgba(0,0,0,0.1)
```

### مثال 3: بطاقة معلومات مرتفعة (Card)

```xml
<element type="shape">
  <shape_type>rectangle</shape_type>
  <background_color>#FFFFFF</background_color>
  <border_radius>8</border_radius>
  <box_shadow>0 4px 12px rgba(0,0,0,0.1)</box_shadow>
</element>
```

### مثال 4: نص بتدرج لوني (Gradient Text)
```xml
<element type="text">
  <content>TOTAL</content>
  <background_color>linear-gradient(90deg, #667eea, #764ba2)</background_color>
  <-webkit-background-clip>text</-webkit-background-clip>
  <color>transparent</color>
</element>
```
