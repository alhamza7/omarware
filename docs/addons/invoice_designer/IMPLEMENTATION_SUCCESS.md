```bash

# 3. استخدم!
# افتح POS Perfume Order → زر "طباعة مع المصمم"
```

### من الواجهة

```
1. POS Perfume → Orders
2. افتح طلب
3. اختر قالب (اختياري)
4. اضغط "طباعة مع المصمم"
   أو "فتح المصمم" للتخصيص
```

## 🎨 أمثلة الاستخدام

### مثال 1: استخدام القالب الجاهز

```
1. افتح طلب POS
2. اضغط "طباعة مع المصمم"
3. احصل على PDF جاهز فوراً!
```

### مثال 2: تخصيص القالب

```
1. افتح طلب POS
2. اضغط "فتح المصمم"
3. أضف/عدّل العناصر
4. احفظ
5. اطبع!
```

### مثال 3: إنشاء قالب جديد

```
1. Invoice Designer → Templates → Create
2. املأ المعلومات
3. احفظ → "فتح المصمم"

5. احفظ
6. استخدم في الطلبات
```
