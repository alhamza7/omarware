---

## ما الجديد؟

### 1. واجهة مصمم مرئية كاملة ✨

الآن يمكنك تصميم فواتير مخصصة بالكامل بدون كتابة كود!

**المميزات:**
- 🖱️ سحب وإفلات (Drag & Drop)
- 👁️ معاينة مباشرة
- 🔍 تكبير/تصغير
- 📐 شبكة إرشادية
- ↶↷ تراجع/إعادة

### 2. تحكم كامل بكل تفاصيل الفاتورة 🎨

**10 أنواع عناصر:**
- 📝 نص ثابت
- 🔄 حقول ديناميكية
- 🖼️ صور وشعارات
- 📊 جداول
- 🔲 أشكال
- ➖ خطوط
- 📷 باركود
- 🔳 QR Code
- ⭐ أيقونات
- 🎨 تدرجات لونية

**50+ خاصية للتحكم:**
- الخطوط (9 أوزان، عربي + إنجليزي)
- الألوان (منتقي لوني متقدم)
- الموقع والحجم
- التأثيرات (ظلال، شفافية)
- وأكثر...

### 3. دمج كامل مع POS Perfume 🔗

**في نموذج الطلب:**
- زر **"طباعة مع المصمم"** ← PDF فوري
- زر **"فتح المصمم"** ← تخصيص كامل
- حقل **"قالب الفاتورة"** ← اختيار القالب

### 4. قالبان جاهزان للاستخدام 📋

#### القالب الكلاسيكي
- تصميم أنيق ومهني
- يعمل افتراضياً
- جاهز للطباعة مباشرةً

#### القالب العصري
- تصميم حديث بألوان جذابة
- QR Code
- تأثيرات متقدمة

## كيف تستخدمه؟

### الطريقة الأسهل (3 خطوات)

```
1. افتح طلب من POS Perfume
2. اضغط "طباعة مع المصمم"
3. احصل على PDF جاهز! ✅
```

### للتخصيص الكامل

```
1. افتح طلب
2. اضغط "فتح المصمم"
3. أضف/عدّل العناصر:
   - اسحب العناصر
   - غيّر الألوان
   - عدّل الخطوط
   - أضف صور
4. احفظ
5. اطبع! ✅
```

## دعم فني

### إذا واجهت أي مشكلة:

1. راجع **QUICK_START_AR.md** (قسم حل المشاكل)
2. راجع **README.md** (قسم Troubleshooting)
3. اتصل بالدعم الفني

### مشاكل شائعة وحلولها

#### العنصر لا يظهر؟
- تحقق من Z-Index (قد يكون خلف عنصر آخر)

#### الصورة لا تظهر؟
- تأكد من رفع الصورة بشكل صحيح

#### الجدول فارغ؟
- اسم الحقل يجب أن يكون: `order_line_ids`
