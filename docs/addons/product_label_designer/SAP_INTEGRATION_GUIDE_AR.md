# 🔄 دليل تكامل SAP - طباعة الليبلات المستمرة

## نظرة عامة

تم إضافة نظام متكامل لطباعة ليبلات المنتجات مباشرة من SAP باستخدام قارئ الباركود. النظام يعمل بشكل مستمر ويطبع تلقائياً عند مسح أي باركود.

---

## 🎯 الميزات الرئيسية

### 1. **واجهة طباعة مستمرة**
- واجهة ثابتة تبقى مفتوحة طوال فترة العمل
- مسح باركود → بحث في SAP → طباعة فورية
- لا حاجة لأي تدخل يدوي

### 2. **تكامل مباشر مع SAP**
- البحث الفوري عن المنتج باستخدام الباركود
- جلب اسم المنتج من SAP
- جلب وحدة القياس الفرعية من SAP
- تحديث تلقائي للبيانات

### 3. **إحصائيات مباشرة**
- عدد الليبلات المطبوعة
- عدد النجاحات
- عدد الأخطاء

---

## 📋 خطوات الإعداد

### الخطوة 1: إعداد القالب

1. اذهب إلى: **المخزون → Product Labels → Label Templates**
2. افتح القالب الذي تريد استخدامه أو أنشئ قالباً جديداً
3. انتقل إلى تبويب **"SAP Integration"**
4. قم بتفعيل **"Enable SAP Mode"**
5. أدخل إعدادات SAP:
   ```
   SAP API URL: https://your-sap-server.com/api
   SAP API Key: your-api-key-here
   ```

### الخطوة 2: إعداد عرض وحدة القياس

في نفس التبويب:
- ✅ فعّل **"Show Unit of Measure"**
- حدد موضع عرض وحدة القياس (X, Y)
- اختر حجم الخط والمحاذاة

### الخطوة 3: تصميم القالب

استخدم **Visual Designer** لترتيب العناصر:
- اسم المنتج
- الباركود
- وحدة القياس
- السعر (اختياري)
- الكود (اختياري)

---

## 🖨️ استخدام النظام

### فتح واجهة الطباعة المستمرة

1. اذهب إلى: **المخزون → Product Labels → SAP Label Printer (Barcode Scan)**
2. ستفتح واجهة جديدة مخصصة للطباعة

### العملية التلقائية

1. **المسح**: قم بمسح الباركود باستخدام قارئ الباركود
2. **البحث**: يتم البحث تلقائياً في SAP
3. **العرض**: تظهر معلومات المنتج
4. **الطباعة**: يتم إرسال أمر الطباعة تلقائياً
5. **الجاهزية**: النظام جاهز للباركود التالي

⏱️ **المدة الكلية**: 1-2 ثانية فقط!

## 🔌 إعداد SAP API

### متطلبات API

يجب أن يوفر SAP API الخاص بك endpoint لجلب بيانات المنتج:

**Endpoint**: `GET /product/lookup`

**Parameters**:
```json
{
  "barcode": "123456789"
}
```

**Response المتوقع**:
```json
{
  "success": true,
  "product_name": "عطر فرنسي 50 مل",
  "uom": "قطعة",
  "barcode": "123456789",
  "price": 150.00,
  "code": "PRD-001"
}
```

### مثال على التكامل

إذا كان لديك SAP API مختلف، يمكنك تعديل الكود في:
```python
# addons/product_label_designer/models/product_label.py
# Method: get_sap_product_info()
```

## 🔧 استكشاف الأخطاء

### المشكلة: "SAP mode not enabled"
**الحل**: تأكد من تفعيل "Enable SAP Mode" في القالب

### المشكلة: "Connection timeout to SAP"
**الحل**: 
- تحقق من SAP API URL
- تأكد من الاتصال بالشبكة
- زيادة timeout في الكود

### المشكلة: "SAP API returned status 401"
**الحل**: تحقق من SAP API Key

### المشكلة: الطباعة لا تعمل تلقائياً
**الحل**:
- تأكد من إعدادات الطابعة في المتصفح
- السماح للنافذة المنبثقة بالطباعة
- استخدم Chrome أو Firefox

---

## 📊 البيانات المخزنة

عند المسح الأول، يتم حفظ:
- `sap_product_name`: اسم المنتج من SAP
- `sap_uom`: وحدة القياس من SAP
- `last_sap_sync`: وقت آخر مزامنة

يمكنك رؤية هذه البيانات في صفحة المنتج.

## 🚀 نصائح للأداء الأفضل

1. **استخدم قارئ باركود USB جيد**
   - يفضل قارئ يدعم المسح السريع
   - تأكد من إعداده على Enter بعد المسح

2. **اتصال شبكة مستقر**
   - اتصال سريع بـ SAP ضروري
   - يفضل اتصال LAN أو WiFi قوي

3. **طابعة ليبلات حرارية**
   - أسرع في الطباعة
   - لا تحتاج حبر

4. **قالب بسيط**
   - استخدم عناصر أقل للطباعة الأسرع
   - تجنب الصور الكبيرة

## 📝 ملاحظات مهمة

⚠️ **أمان API Key**
- لا تشارك SAP API Key
- استخدم HTTPS فقط
- غيّر المفتاح بشكل دوري

✅ **التوافق**
- يعمل على Chrome, Firefox, Edge
- يحتاج JavaScript مُفعّل
- يحتاج Pop-up مسموح

📌 **الحفظ التلقائي**
- المنتجات تُحفظ تلقائياً في Odoo
- يمكن تحديث البيانات لاحقاً
- التاريخ يُسجل في `last_sap_sync`

## 🆘 الدعم

إذا واجهت أي مشكلة:

1. تحقق من logs في Odoo:
   ```
   Settings → Technical → Logging
   ابحث عن: "SAP"
   ```

2. تحقق من Console في المتصفح (F12)

3. جرّب الإعدادات التالية:
   - قالب مختلف
   - API URL مختلف
   - متصفح مختلف
