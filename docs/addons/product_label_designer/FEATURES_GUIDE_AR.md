# دليل المميزات الكامل - Product Label Designer

## 🎨 المميزات الجديدة المضافة

### ✅ 1. الاسم الأجنبي (Foreign Name)
- إضافة اسم المنتج بلغة أخرى (إنجليزي، فرنسي، إلخ)
- موضع منفصل قابل للتعديل
- دعم RTL و LTR

**كيفية الاستخدام:**
```
1. افتح المنتج
2. أسفل "الاسم" مباشرة → حقل "Foreign Name"
3. مثال: "Rose Perfume 30ml"
4. في القالب: فعّل "Show Foreign Name"
5. في المصمم: حرك موضعه
```

---

### ✅ 2. طباعة A4 Sheet
- طباعة عدة ملصقات على ورقة A4 واحدة
- شبكة قابلة للتخصيص (2×4, 3×6, 4×8)
- توفير الورق والوقت

**الإعدادات:**
```
في القالب → تبويب "A4 Layout":
- Labels per Row: 2
- Labels per Column: 4
- Margin: 2mm
→ المجموع: 8 ملصقات في صفحة واحدة
```

**كيفية الاستخدام:**
```
1. اختر منتجات (عدة منتجات)
2. إجراء → Print Labels
3. Print Mode: اختر "A4 Sheet"
4. اطبع!
```

**أمثلة للشبكة:**
- 80×60mm → 2×4 = 8 ملصقات
- 70×40mm → 3×6 = 18 ملصق
- 50×30mm → 4×9 = 36 ملصق

---

### ✅ 3. المصمم المرئي (Visual Designer)
**Drag & Drop** لتصميم الملصق بطريقة تفاعلية!

**المميزات:**
- 🖱️ **سحب وإفلات**: حرك أي عنصر بالماوس
- ⌨️ **لوحة المفاتيح**: الأسهم للتحريك الدقيق
- 📏 **مواضع دقيقة**: X, Y بالملليمتر
- 👁️ **معاينة فورية**: شاهد التغييرات مباشرة
- 💾 **حفظ تلقائي**: كل تحريك يُحفظ

**كيفية الاستخدام:**
```
1. المخزون → Label Templates
2. افتح/أنشئ قالب
3. تبويب "Visual Designer"
4. اضغط "Open Visual Designer"
5. شاشة جديدة تفتح مع المصمم
```

**في المصمم:**
- **اختر عنصر**: انقر عليه
- **حرّك**: اسحبه بالماوس
- **دقيق**: الأسهم (1mm)، Shift+الأسهم (10mm)
- **احفظ**: يحفظ تلقائياً

---

### ✅ 4. QR Code
- إنشاء QR Code لرابط المنتج تلقائياً
- عند المسح: يفتح صفحة المنتج
- حجم قابل للتعديل
- موضع قابل للتحريك

**كيفية الاستخدام:**
```
1. في القالب → Display Options
2. فعّل "Show QR Code"
3. في Visual Designer: اسحب QR Code
4. اسحب الزاوية لتغيير الحجم
```

**ما يحتويه QR:**
```
http://yoursite.com/shop/product/[product_id]
```

---

### ✅ 5. رفع الصور من المصمم
**الآن يمكنك رفع الخلفية والشعار مباشرة من المصمم!**

**المميزات:**
- 📤 **رفع مباشر**: من داخل المصمم
- 👁️ **معاينة فورية**: تظهر الصورة مباشرة
- 🗑️ **حذف**: إزالة الصورة بزر واحد
- 💾 **حفظ تلقائي**: يحفظ في قاعدة البيانات

**كيفية الاستخدام:**
```
1. افتح Visual Designer
2. في Sidebar:
   
   🖼️ Background Image:
   - Upload Background → اختر صورة
   - معاينة فورية
   - Remove Background لحذفها
   
   🏷️ Logo Image:
   - Upload Logo → اختر صورة
   - معاينة فورية
   - Remove Logo لحذفها
```

**الصيغ المدعومة:**
- PNG (موصى به)
- JPG/JPEG
- GIF
- الحجم الأقصى: 5MB

## 🎯 سيناريو كامل: تصميم ملصق عطور

### الخطوة 1: إنشاء القالب
```
المخزون → Label Templates → Create

الاسم: ملصق عطور فيروزي
العرض: 80mm
الارتفاع: 60mm
```

### الخطوة 2: إعدادات العرض
```
Display Options:
☑️ Show Product Name
☑️ Show Foreign Name
☑️ Show Product Code
☑️ Show Price
☑️ Show Barcode
☑️ Show QR Code
☑️ Show Logo
```

### الخطوة 3: A4 Layout
```
Labels per Row: 2
Labels per Column: 4
Margin: 2mm
→ 8 ملصقات في الصفحة
```

### الخطوة 4: افتح المصمم المرئي
```
تبويب "Visual Designer" → "Open Visual Designer"
```

### الخطوة 5: رفع الصور
```
في Sidebar:

🖼️ Background Image:
- Upload Background
- اختر صورة الخطوط الزرقاء
- تظهر فوراً في Canvas

🏷️ Logo:
- Upload Logo
- اختر شعار المحل
- يظهر في الملصق
```

### الخطوة 6: رتب العناصر
```
اسحب كل عنصر للموضع المطلوب:

📝 Name (Arabic): أعلى اليمين
🌐 Foreign Name: تحت الاسم العربي
💰 Price: الوسط (مخفي)
#️⃣ Code: الوسط - كبير - بارز
📊 Barcode: أسفل اليسار
📱 QR Code: أسفل اليمين
🏷️ Logo: أعلى اليسار
```

### الخطوة 7: اختبر الطباعة
```
1. افتح منتج
2. املأ Foreign Name: "Rose Perfume"
3. Print Label
4. Print Mode: "A4 Sheet"
5. Copies: 2
6. Print!
```

## 🎨 نصائح التصميم

### للخلفية:
- ✅ استخدم ألوان فاتحة
- ✅ صور بدقة 300 DPI
- ✅ الحجم الأمثل: 944×708 بكسل لـ 80×60mm
- ✅ PNG للشفافية، JPG للصور العادية

### للشعار:
- ✅ PNG شفاف مفضل
- ✅ حجم موصى: 200×150 بكسل
- ✅ خلفية شفافة للمظهر الأفضل

### للـ QR Code:
- ✅ الحجم الأدنى: 10mm
- ✅ الحجم الموصى: 15-20mm
- ✅ خلفية بيضاء للقراءة الأفضل

```

Print Mode: "A4 Sheet"

```
