## ⌨️ اختصارات مهمة

### في جدول الطلب:
- `Tab` = الانتقال لليمين
- `Enter` = الانتقال للأسفل
- الأسهم = التنقل بحرية

### في البحث:
- اكتب = بحث فوري
- `↓` `↑` = اختيار المنتج
- `Enter` = إضافة للطلب
- **Double Click** = إضافة مباشرة

## 🆘 إذا واجهت مشكلة

### 1. الواجهة لا تظهر
```bash
python odoo-bin -u pos_perfume_custom -d your_db --stop-after-init
# ثم امسح cache المتصفح (Ctrl+Shift+Del)
# ثم اضغط F5
```

### 2. المنتجات لا تظهر
- تحقق من "Can be Sold" مفعل
- تأكد أن المنتج غير مؤرشف

### 3. الحسابات خاطئة
- تحقق من الأسعار
- راجع نسب التخفيض (0-100)

### 4. مشاكل أخرى
راجع `UPGRADE_INSTRUCTIONS.md` قسم "حل المشاكل"
