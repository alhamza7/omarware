# ✅ إضافة عرض وحدة القياس في نتائج البحث

## 📝 **التغييرات المطبقة:**

### 1️⃣ **تعديلات الـ API (Backend):**

#### ملف: `src/server.js`

**التغيير الأول**: إضافة `uom` في API البحث
```sql
-- قبل:
SELECT i.id, i.item_code, i.item_name, NULL as barcode_id, NULL as barcode
FROM items i

-- بعد:
SELECT i.id, i.item_code, i.item_name, NULL as barcode_id, NULL as barcode, NULL as uom
FROM items i

-- وفي الـ UNION:
SELECT i.id, i.item_code, i.item_name, b.id as barcode_id, b.barcode, b.uom
FROM barcodes b
```

**التغيير الثاني**: إضافة `uom` في API جلب الصنف بالكود
```sql
-- قبل:
SELECT i.id, i.item_code, i.item_name, b.id as barcode_id, b.barcode

-- بعد:
SELECT i.id, i.item_code, i.item_name, b.id as barcode_id, b.barcode, b.uom
```

### 2️⃣ **تعديلات تطبيق الويب:**

#### ملف: `public/app.js`

**عرض وحدة القياس في نتائج البحث:**
```javascript
const uomText = it.uom ? ` (${escapeHtml(it.uom)})` : "";
row.innerHTML = `
  <div class="result__meta">
    <div class="result__code">${escapeHtml(it.item_code)}</div>
    <div class="result__name">${escapeHtml(it.item_name)}${uomText}</div>

  </div>
`;
```

**عرض وحدة القياس في نافذة الجرد:**
```javascript
const uomText = item.uom ? ` - ${item.uom}` : "";
dlgMeta.textContent = `${item.item_code} — ${item.item_name}${uomText}${barcodeText}`;
```

**عرض وحدة القياس في نافذة "تم الجرد مسبقاً":**
```javascript

// يتم استخدامها في العرض
```

## 🗄️ **مصدر البيانات:**

وحدة القياس (`uom`) مخزنة في جدول `barcodes`:
```sql
CREATE TABLE barcodes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  item_id INTEGER NOT NULL,
  barcode TEXT NOT NULL,
  uom TEXT,  -- ← وحدة القياس
  ...
);
```

**ملاحظة:** 
- إذا كان للصنف باركود، يتم عرض وحدة القياس المرتبطة بالباركود
- إذا لم يكن له باركود، لن تظهر وحدة القياس (NULL)
