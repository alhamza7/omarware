## ✨ المميزات الجديدة

### 1️⃣ إصلاح خطأ اتصال SAP TLS

#### المشكلة السابقة:
```
Error: Client network socket disconnected before secure TLS connection was established
```

#### الحل:
- ✅ تحسين إعدادات HTTPS Agent
- ✅ إضافة timeout مناسب (30 ثانية)
- ✅ تحديد الحد الأدنى لإصدار TLS (TLSv1.2)
- ✅ تحسين معالجة الأخطاء مع رسائل واضحة
- ✅ إضافة وظيفة اختبار الاتصال قبل تسجيل الدخول

#### الكود المحسّن:
```javascript
// في src/sap_client.js
httpsAgent: new https.Agent({
  rejectUnauthorized: false,
  keepAlive: true,
  maxSockets: 10,
  maxFreeSockets: 5,
  timeout: 30000,
  minVersion: 'TLSv1.2'
})
```

### 4️⃣ مطابقة الكميات وحساب الفرق

#### الآلية:
1. النظام يجلب الكمية الحالية من SAP لكل صنف
2. يحسب الفرق: `الفرق = الجرد - SAP المتاح`
3. يحسب الكمية النهائية: `الكمية النهائية = SAP الحالي + الفرق`

#### أعمدة Excel الجديدة:
| العمود | الوصف |
|--------|-------|
| CountedQty | الكمية المجرودة |
| SAP_Available | الكمية المتاحة في SAP (وقت التصدير) |
| Difference | الفرق (موجب = زيادة، سالب = نقص) |
| UpdatedQty | الكمية النهائية للتحديث في SAP |

#### مثال:
```
CountedQty: 100
SAP_Available: 80
Difference: +20
UpdatedQty: 100 (SAP يجب تحديثه إلى 100)
```

### 5️⃣ جلب كميات SAP أثناء التصدير

#### المميزات:
- ✅ **جلب حي (Real-time)** لكميات SAP وقت التصدير
- ✅ لا يعتمد على البيانات المحفوظة القديمة
- ✅ دقة 100% في الأرقام

#### الكود:
```javascript
for (const row of rows) {
  // جلب الكمية الحالية من SAP
  const sapData = await sapClient.getItemQuantity(row.item_code, warehouseId);
  
  if (sapData) {
    sapAvailableCurrent = sapData.available;
    difference = row.last_qty - sapAvailableCurrent;
    updatedQty = sapAvailableCurrent + difference;
  }
}
```

## ❓ الأسئلة الشائعة

### س: كيف أصبح مديراً؟
**ج:** يجب تغيير `role` في قاعدة البيانات إلى `'admin'`:
```sql
UPDATE users SET role = 'admin' WHERE username = 'your_username';
```

### س: لماذا لا يتصل SAP؟
**ج:** تحقق من:
1. عنوان SAP في `.env` أو `src/sap_config.js`
2. بيانات الدخول صحيحة
3. الخادم يعمل والشبكة متصلة
4. استخدم "اختبار اتصال SAP" من لوحة التحكم

### س: كيف أرفع ملفات Excel؟
**ج:** 
1. يجب أن تكون مديراً
2. افتح `/admin`
3. اسحب الملفات أو انقر على المنطقة المخصصة

### س: ما هو الفرق بين CountedQty و UpdatedQty؟
**ج:**
- `CountedQty`: الكمية التي تم جردها
- `UpdatedQty`: الكمية النهائية التي يجب تحديثها في SAP (تأخذ في الاعتبار الكمية الحالية في SAP)
