## 🔧 **استكشاف الأخطاء:**

### ❓ **لا تظهر وحدة القياس؟**

#### **السبب 1: السيرفر القديم**
```bash
# أوقف السيرفر الحالي
Ctrl+C

# شغّل السيرفر الجديد
node src/server.js
```

#### **السبب 2: الـ cache في المتصفح**
```
اضغط: Ctrl+Shift+R (Hard Refresh)
أو: F12 → Network → Disable cache
```

#### **السبب 3: نسخة الموبايل القديمة**
```
احذف التطبيق القديم
ثبّت: inventory_app_v3_with_uom.apk
```

#### **السبب 4: البحث عن منتج بدون باركود**
```
وحدة القياس مرتبطة بالباركود فقط
ابحث عن منتج له باركود
```

## 🧪 **اختبار سريع:**

1. افتح Console (F12)
2. نفذ هذا الأمر:
```javascript
fetch('/api/items/search?q=14145')
  .then(r => r.json())
  .then(d => console.log(d.items[0]))
```

3. لاحظ النتيجة:
```json
{
  "id": 123,
  "item_code": "14145",
  "item_name": "...",
  "barcode": "14145",
  "uom": "كغم"  ← يجب أن تكون موجودة!
}
```
