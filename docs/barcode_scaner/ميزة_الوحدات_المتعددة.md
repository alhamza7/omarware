# 📦 ميزة الوحدات المتعددة - دليل الاستخدام

## 🎯 الهدف

تمكين المستخدمين من إدخال الكميات بوحدات متعددة (قطعة، درزن، كارتون) لتسهيل الجرد وتوثيق التفاصيل.

---

## 📱 كيفية الاستخدام في التطبيق

### 1. الأصناف ذات الوحدات المدعومة:

النظام يعرض **3 حقول** للأصناف التي وحدة قياسها:
- **قطعة** أو **قطعه** أو **Piece** أو **PCS**
- **باكيت** أو **Packet** أو **Pack**
- **سيت** أو **Set**
- **درزن** أو **Dozen**
- **كارتون** أو **Carton**

### 2. شاشة الجرد:

عند مسح باركود لصنف من الأنواع أعلاه:

```
┌─────────────────────────────┐
│      إضافة كمية             │
├─────────────────────────────┤
│ PEN001 — قلم رصاص           │
│                              │
│ ┌───────────────────────┐   │
│ │ قطعة:     [  5  ]     │   │
│ └───────────────────────┘   │
│                              │
│ ┌───────────────────────┐   │
│ │ درزن:     [  2  ]     │   │
│ │ (1 درزن = 12 قطعة)    │   │
│ └───────────────────────┘   │
│                              │
│ ┌───────────────────────┐   │
│ │ كارتون:   [  1  ]     │   │
│ │ (1 كارتون = 144 قطعة) │   │
│ └───────────────────────┘   │
│                              │
│ ┏━━━━━━━━━━━━━━━━━━━━━━┓   │
│ ┃ الإجمالي: 173 قطعة   ┃   │
│ ┗━━━━━━━━━━━━━━━━━━━━━━┛   │
│                              │
│     [إلغاء]    [حفظ ✓]     │
└─────────────────────────────┘
```

**الحساب التلقائي:**
```
الإجمالي = 5 + (2 × 12) + (1 × 144)
        = 5 + 24 + 144
        = 173 قطعة
```

### 3. باقي الأصناف:

الأصناف الأخرى (كغ، لتر، متر...إلخ) تظل كما هي:
```
┌─────────────────────────────┐
│      إضافة كمية             │
├─────────────────────────────┤
│ OIL001 — زيت زيتون          │
│                              │
│ ┌───────────────────────┐   │
│ │ الكمية:   [  15  ]    │   │
│ └───────────────────────┘   │
│                              │
│     [إلغاء]    [حفظ ✓]     │
└─────────────────────────────┘
```

## 📊 في تقرير Excel

### الأعمدة الجديدة:

| العمود | الوصف |
|--------|-------|
| `Qty_Pieces` | عدد القطع/الباكيت/السيت المدخل |
| `Qty_Dozen` | عدد الدرزن المدخل |
| `Qty_Carton` | عدد الكراتين المدخل |
| `Qty_Total` | الإجمالي المحسوب (بالوحدة الأساسية) |
| `CountedQty` | الكمية المجردة (= Qty_Total) |

### مثال على السطر في Excel:

```
ItemCode | ItemName | UOM   | Qty_Pieces | Qty_Dozen | Qty_Carton | Qty_Total | CountedQty | SAP_Current | Difference
---------|----------|-------|------------|-----------|------------|-----------|------------|-------------|------------
PEN001   | قلم      | قطعة  | 5          | 2         | 1          | 173       | 173        | 150         | 23
PACK001  | دفتر     | باكيت | 3          | 1         | 0          | 15        | 15         | 10          | 5
OIL001   | زيت      | لتر   |            |           |            |           | 15         | 12          | 3
```

**ملاحظة:**
- الأصناف التي ليس لها وحدات متعددة تكون الأعمدة `Qty_Pieces`، `Qty_Dozen`، `Qty_Carton` فارغة
- حسابات الفروقات مع SAP تتم على `Qty_Total` فقط

## 🔧 التفاصيل التقنية

### 1. معادلات التحويل:

```
1 درزن = 12 وحدة أساسية (قطعة/باكيت/سيت)
1 كارتون = 12 درزن = 144 وحدة أساسية

الإجمالي = وحدة_أساسية + (درزن × 12) + (كارتون × 144)
```

### 2. قاعدة البيانات:

**جدول `counts`:**
```sql
qty_pieces REAL   -- الوحدة الأساسية
qty_dozen REAL    -- عدد الدرزن
qty_carton REAL   -- عدد الكراتين
qty_total REAL    -- الإجمالي المحسوب
qty REAL          -- للتوافق (= qty_total)
```

### 3. API Endpoint:

**POST `/api/counts`**
```json
{
  "item_id": 123,
  "qty": 173,
  "qty_pieces": 5,
  "qty_dozen": 2,
  "qty_carton": 1,
  "sap_available": 150
}
```

**Response:**
```json
{
  "ok": true,
  "id": 456,
  "qty_total": 173
}
```

## 📝 أمثلة واقعية

### مثال 1: جرد الأقلام

```
الوحدة: قطعة
الإدخال:
  - قطعة: 8
  - درزن: 3
  - كارتون: 2

الإجمالي = 8 + (3 × 12) + (2 × 144)
         = 8 + 36 + 288
         = 332 قطعة

في Excel:
Qty_Pieces: 8
Qty_Dozen: 3
Qty_Carton: 2
Qty_Total: 332
```

### مثال 2: جرد الباكيتات

```
الوحدة: باكيت
الإدخال:
  - باكيت: 5
  - درزن: 1
  - كارتون: 0

الإجمالي = 5 + (1 × 12) + (0 × 144)
         = 5 + 12 + 0
         = 17 باكيت

في Excel:
Qty_Pieces: 5
Qty_Dozen: 1
Qty_Carton: 0
Qty_Total: 17
```

### مثال 3: جرد السوائل (لا يدعم الوحدات المتعددة)

```
الوحدة: لتر
الإدخال:
  - الكمية: 25

في Excel:
Qty_Pieces: (فارغ)
Qty_Dozen: (فارغ)
Qty_Carton: (فارغ)
Qty_Total: (فارغ)
CountedQty: 25
```
