# 🚀 دليل البدء السريع - المميزات الجديدة

## ⚡ ابدأ الآن في 3 خطوات

### 1️⃣ تشغيل السيرفر
```bash
node src/server.js
```

### 2️⃣ افتح المتصفح
```
http://localhost:3000
```

### 3️⃣ سجل دخول كمدير
```
Username: admin
Password: (كلمة المرور المحددة في قاعدة البيانات)
```

---

## 🎛️ لوحة التحكم الجديدة

### الوصول:
- من أي صفحة، انقر على زر **"🎛️ لوحة التحكم"** (أخضر في الأعلى)
- أو اذهب مباشرة إلى: `http://localhost:3000/admin`

### ما يمكنك فعله:

#### 📊 عرض الإحصائيات
- إجمالي الأصناف
- إجمالي الباركودات
- عدد المستخدمين
- عدد الجردات

#### 📥 رفع ملفات Excel
1. اسحب ملف Excel وأفلته في المنطقة المخصصة
2. أو انقر واختر الملف
3. النظام يستورد البيانات تلقائياً

**تنسيق الملف المطلوب:**
| ItemCode | ItemName | Barcode | UOM |
|----------|----------|---------|-----|
| ITEM001  | صنف 1    | 123456  | PCS |
| ITEM002  | صنف 2    | 789012  | BOX |

#### 📦 إدارة البيانات
- **عرض الأصناف**: جميع المنتجات في النظام
- **عرض المستخدمين**: قائمة بجميع المستخدمين
- **عرض الباركودات**: جميع الباركودات المسجلة

#### 🔌 اختبار SAP
- انقر على **"اختبار اتصال SAP"**
- سيظهر لك إذا كان SAP متصل أم لا
- وسبب المشكلة إن وجدت

#### 🗑️ حذف البيانات
- **حذف جردات المخزن**: يحذف جردات المخزن الحالي فقط
- **حذف كل الجردات**: يحذف جميع الجردات من جميع المخازن ⚠️

---

## 📥 تصدير Excel (الإدارة فقط)

### من صفحة التقارير:
1. افتح **التقارير** (`/reports`)
2. اختر الفلتر المطلوب (الكل / المجرودة / المتبقية)
3. انقر **"📥 تصدير Excel"** (أخضر)

### ما يحتويه الملف المصدّر:

#### Sheet 1: تقرير الجرد الكامل
- كود الصنف
- اسم الصنف
- الباركود
- وحدة القياس
- **الكمية المجرودة**
- **كمية SAP المتاحة (الحالية)**
- **الفرق** (موجب = زيادة، سالب = نقص)
- **الكمية النهائية** (للتحديث في SAP)
- اسم المستخدم
- تاريخ الجرد

#### Sheet 2: الملخص
- تاريخ التصدير
- **اسم المستخدم** الذي قام بالتصدير
- رقم المخزن
- الإحصائيات

## 🔧 إصلاح مشكلة SAP

### المشكلة القديمة:
```
❌ Client network socket disconnected before secure TLS connection was established
```

### الحل:
✅ **تم إصلاحها تلقائياً!**

النظام الآن يدعم:
- اتصال TLS محسّن
- timeout أطول (30 ثانية)
- إعادة محاولة تلقائية
- رسائل خطأ واضحة

### كيف تتحقق:
1. افتح لوحة التحكم (`/admin`)
2. انقر **"🔌 اختبار اتصال SAP"**
3. سيظهر لك:
   - ✅ **متصل**: كل شيء يعمل
   - ⚠️ **مفعل ولكن غير متصل**: تحقق من بيانات الدخول
   - ❌ **غير مفعل**: فعّل SAP من ملف `.env`

## 💡 نصائح مهمة

### 1. تصدير التقارير:
- دائماً صدّر التقارير **قبل تحديث SAP**
- الملف يحتوي على العمود `UpdatedQty` الجاهز للتحديث

### 2. رفع ملفات Excel:
- يمكنك رفع عدة ملفات دفعة واحدة
- النظام يتخطى الأصناف المكررة تلقائياً

### 3. اختبار SAP:
- اختبر الاتصال قبل بدء الجرد
- إذا لم يكن متصلاً، النظام يعمل عادي لكن بدون بيانات SAP

### 4. الفرق في Excel:
```
الفرق = الكمية المجرودة - كمية SAP المتاحة

أمثلة:
- الفرق +20: يعني زيادة 20 قطعة
- الفرق -10: يعني نقص 10 قطع
- الفرق 0: يعني مطابق تماماً
```

## 🐛 حل المشاكل

### مشكلة: لا أرى زر لوحة التحكم
**الحل:** تأكد أن حسابك `role = 'admin'` في قاعدة البيانات

### مشكلة: SAP لا يتصل
**الحل:** 
1. تحقق من ملف `.env` أو `src/sap_config.js`
2. تأكد من صحة:
   - `SAP_SERVICE_LAYER_URL`
   - `SAP_COMPANY_DB`
   - `SAP_USERNAME`
   - `SAP_PASSWORD`
3. استخدم "اختبار اتصال SAP"

### مشكلة: لا يمكنني رفع ملفات Excel
**الحل:**
1. تأكد أنك مدير
2. الملف يجب أن يكون `.xlsx` أو `.xls`
3. حجم الملف أقل من 50MB

### مشكلة: التصدير بطيء
**السبب:** النظام يجلب بيانات SAP لكل صنف (real-time)
**عادي:** قد يستغرق بضع ثوان حسب عدد الأصناف
