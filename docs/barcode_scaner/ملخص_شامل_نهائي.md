### 4️⃣ حساب الفرق التلقائي 🧮

**الآلية:**
```javascript
الفرق = الكمية المجرودة - SAP المتاح الحالي
الكمية النهائية = SAP المتاح الحالي + الفرق
```

**مثال:**
```
الكمية المجرودة: 100
SAP المتاح: 80
الفرق: +20 (زيادة)
الكمية النهائية: 100 (يجب تحديث SAP إلى 100)
```

**الفوائد:**
- ✅ معرفة الزيادات والنواقص فوراً
- ✅ الكمية النهائية جاهزة للتحديث
- ✅ لا حاجة لحسابات يدوية
- ✅ دقة 100%

## 🚀 كيف تبدأ

### 1. التثبيت:
```bash
npm install
```

### 2. إنشاء ملف .env:
```bash
node create_env.js
```

### 3. تعديل إعدادات SAP في .env:
```env
SAP_ENABLED=true
SAP_SERVICE_LAYER_URL=https://192.168.15.50:50000/b1s/v1
SAP_COMPANY_DB=NBS_LIVE_NEW
SAP_USERNAME=manager
SAP_PASSWORD=na54321
```

### 4. تشغيل السيرفر:
```bash
node src/server.js
```

### 5. فتح المتصفح:
```
http://localhost:3000
```

### 6. تسجيل الدخول كمدير:
```
Username: admin
Password: [كلمة المرور من قاعدة البيانات]
```

### 7. اختبار SAP:
- افتح `/admin`
- انقر "🔌 اختبار SAP"
