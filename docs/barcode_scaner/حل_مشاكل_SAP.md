### الحل 2️⃣: التحقق من إعدادات الشبكة

#### أ. تحقق من اتصال الشبكة:

```bash
# في PowerShell أو CMD
ping 192.168.15.50
```

**يجب أن يرد السيرفر:**
```
Reply from 192.168.15.50: bytes=32 time=1ms TTL=128
```

#### ب. تحقق من المنفذ (Port):

```bash
# في PowerShell
Test-NetConnection -ComputerName 192.168.15.50 -Port 50000
```

**يجب أن تحصل على:**
```
TcpTestSucceeded : True
```

---

### الحل 3️⃣: التحقق من خادم SAP

#### الأشياء التي يجب التحقق منها:

1. ✅ **Service Layer يعمل على السيرفر**
   - افتح SAP Business One
   - تأكد أن Service Layer مثبت ويعمل

2. ✅ **الشهادة SSL/TLS صحيحة**
   - النظام يتجاهل شهادات SSL حالياً (للتطوير)
   - لكن تأكد أن SAP Service Layer يستخدم HTTPS

3. ✅ **Firewall لا يمنع الاتصال**
   - تأكد أن المنفذ 50000 مفتوح
   - افحص Windows Firewall على سيرفر SAP

## 🔍 تشخيص الأخطاء

### خطأ: "Connection refused"
**السبب:** SAP Service Layer لا يعمل  
**الحل:** 
- شغّل SAP Service Layer على السيرفر
- تحقق من إعدادات الخدمة في Windows Services

### خطأ: "ETIMEDOUT"
**السبب:** الشبكة بطيئة أو Firewall يمنع  
**الحل:**
- تحقق من Firewall
- تحقق من اتصال الشبكة
- جرب من كمبيوتر آخر على نفس الشبكة

### خطأ: "socket disconnected before TLS"
**السبب:** مشكلة في شهادة SSL أو إصدار TLS  
**الحل:**
- ✅ **تم حله في الكود الجديد!**
- النظام الآن يدعم TLSv1.2 مع إعدادات محسنة
- جرب HTTP مؤقتاً للاختبار

### خطأ: "401 Unauthorized"
**السبب:** بيانات الدخول خاطئة  
**الحل:**
- تحقق من اسم المستخدم وكلمة المرور
- تحقق من اسم قاعدة البيانات (SAP_COMPANY_DB)
