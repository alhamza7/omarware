# نظام التحكم التلقائي في حجم الخط

## كيف يعمل؟

تم تطوير نظام ذكي يقوم بتعديل حجم خط اسم المنتج تلقائياً بناءً على طول النص:

### جدول المضاعفات:

| طول النص (عدد الأحرف) | المضاعف | الوصف | مثال |
|----------------------|---------|-------|------|
| أقل من 10 | ×1.8 | قصير جداً | "ماء" |
| 10 - 20 | ×1.4 | قصير | "ماء معدني صغير" |
| 21 - 35 | ×1.0 | متوسط | "ماء معدني طبيعي 500 مل" |
| 36 - 50 | ×0.75 | طويل | "ماء معدني طبيعي من الينابيع الجبلية 500 مل" |
| أكثر من 50 | ×0.6 | طويل جداً | "ماء معدني طبيعي من الينابيع الجبلية النقية معبأ بتقنية حديثة 500 مل" |

### مثال عملي:

إذا كان حجم الخط الأساسي في القالب = **12pt**:

- نص قصير (8 أحرف): `12pt × 1.8 = 21.6pt` ✨
- نص متوسط (25 حرف): `12pt × 1.0 = 12pt` ✅
- نص طويل (45 حرف): `12pt × 0.75 = 9pt` 📏
- نص طويل جداً (60 حرف): `12pt × 0.6 = 7.2pt` 🔍

## الكود المستخدم:

```xml
<t t-set="name_text" t-value="o.name or ''"/>
<t t-set="name_length" t-value="len(name_text)"/>
<!-- حساب المضاعف الذكي -->
<t t-set="font_multiplier" t-value="1.8 if name_length &lt; 10 else (1.4 if name_length &lt;= 20 else (1.0 if name_length &lt;= 35 else (0.75 if name_length &lt;= 50 else 0.6)))"/>
<!-- تطبيق الحجم الديناميكي -->
<div class="product-name" t-attf-style="font-size: calc({{template.font_size_name}}pt * {{font_multiplier}}) !important;">
    <t t-esc="name_text"/>
</div>
```

## المزايا:

✅ **تلقائي بالكامل** - لا يحتاج تدخل يدوي  
✅ **ذكي** - يتكيف مع طول كل منتج  
✅ **مرن** - يمكن تعديل القيم بسهولة  
✅ **دقيق** - يحسب بالبيكسل  
✅ **متناسق** - يحافظ على الشكل العام  

## التخصيص:

### لتغيير نقاط التحول:
```xml
<!-- حالياً: 10, 20, 35, 50 -->
<t t-set="font_multiplier" t-value="1.8 if name_length &lt; 15 else (1.4 if name_length &lt;= 25 else ...)"/>
```

### لتغيير المضاعفات:
```xml
<!-- حالياً: 1.8, 1.4, 1.0, 0.75, 0.6 -->
<t t-set="font_multiplier" t-value="2.0 if name_length &lt; 10 else (1.5 if name_length &lt;= 20 else ...)"/>
```

### لإضافة مستويات أخرى:
```xml
<t t-set="font_multiplier" t-value="
    2.5 if name_length &lt; 5 else (
    2.0 if name_length &lt; 10 else (
    1.5 if name_length &lt; 15 else (
    1.2 if name_length &lt; 20 else (
    1.0 if name_length &lt; 30 else (
    0.8 if name_length &lt; 40 else (
    0.6 if name_length &lt; 50 else 
    0.5
))))))"/>
```

## ملاحظات مهمة:

1. **النظام يعمل لكل منتج على حدة** - كل ملصق يحسب حجمه الخاص
2. **الحجم الأساسي من القالب** - يتم ضربه في المضاعف
3. **يعمل مع العربية والإنجليزية** - يحسب عدد الأحرف فقط
4. **مضمون داخل المساحة** - مع `overflow: hidden` و `text-overflow: ellipsis`

## الاختبار:

جرب مع منتجات مختلفة الأسماء:
- ✅ "ماء" → كبير جداً
- ✅ "ماء معدني" → كبير  
- ✅ "ماء معدني طبيعي 500 مل" → عادي
- ✅ "ماء معدني طبيعي من الينابيع الجبلية النقية 500 مل" → صغير
