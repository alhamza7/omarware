# التحكم في حجم الخط التلقائي من Visual Designer

## 🎨 الميزة الجديدة

الآن يمكنك **التحكم الكامل** في نظام التحكم التلقائي في حجم الخط من واجهة Visual Designer!

## 📍 كيفية الوصول

1. اذهب إلى: **Settings → Label Templates**
2. افتح أي قالب (Template)
3. في تبويب **"Style & Fonts"**
4. مرر للأسفل إلى قسم **"Auto Font Sizing"**

## ⚙️ الإعدادات المتاحة

### 1. تفعيل/تعطيل الميزة
```
☑ Enable Auto Font Sizing
```
- ✅ مفعّل: حجم الخط يتغير تلقائياً حسب طول النص
- ☐ معطّل: حجم الخط ثابت للجميع

---

### 2. Font Multipliers (نسب التكبير/التصغير)

| الحقل | القيمة الافتراضية | الوصف |
|------|-------------------|-------|
| **Very Short Text** | 1.8 | نص قصير جداً (أقل من 10 أحرف) |
| **Short Text** | 1.4 | نص قصير (10-20 حرف) |
| **Medium Text** | 1.0 | نص متوسط (21-35 حرف) |
| **Long Text** | 0.75 | نص طويل (36-50 حرف) |
| **Very Long Text** | 0.6 | نص طويل جداً (أكثر من 50 حرف) |

**مثال:**
- إذا كان `font_size_name = 12pt`
- نص قصير: `12 × 1.8 = 21.6pt` 📈
- نص متوسط: `12 × 1.0 = 12pt` ✅
- نص طويل: `12 × 0.6 = 7.2pt` 📉

---

### 3. Character Thresholds (حدود عدد الأحرف)

| الحقل | القيمة الافتراضية | الوصف |
|------|-------------------|-------|
| **Very Short Threshold** | 10 | الحد الأقصى للنص القصير جداً |
| **Short Threshold** | 20 | الحد الأقصى للنص القصير |
| **Medium Threshold** | 35 | الحد الأقصى للنص المتوسط |
| **Long Threshold** | 50 | الحد الأقصى للنص الطويل |

**مثال على التطبيق:**
```
نص من 8 أحرف:  → Very Short → ×1.8
نص من 15 حرف:  → Short → ×1.4
نص من 30 حرف:  → Medium → ×1.0
نص من 45 حرف:  → Long → ×0.75
نص من 60 حرف:  → Very Long → ×0.6
```

## 🎯 أمثلة الاستخدام

### مثال 1: ملصقات صغيرة (للمنتجات ذات الأسماء الطويلة)

```
✅ Enable Auto Font Sizing
Font Multipliers:
  Very Short: 2.0  ← زيادة للنصوص القصيرة
  Short: 1.5
  Medium: 1.0
  Long: 0.6        ← تصغير أكثر للنصوص الطويلة
  Very Long: 0.4   ← تصغير كبير للنصوص الطويلة جداً
```

### مثال 2: ملصقات كبيرة (مساحة واسعة)

```
✅ Enable Auto Font Sizing
Font Multipliers:
  Very Short: 2.5  ← تكبير كبير
  Short: 2.0
  Medium: 1.5
  Long: 1.2        ← تصغير قليل فقط
  Very Long: 1.0   ← حجم عادي حتى للنصوص الطويلة
```

### مثال 3: تعطيل الميزة (حجم ثابت)

```
☐ Enable Auto Font Sizing
```
→ جميع المنتجات ستستخدم `font_size_name` بدون تعديل

## 🔧 التخصيص المتقدم

### تغيير نقاط التحول (Thresholds)

**السيناريو:** تريد 3 مستويات فقط بدلاً من 5

```
Character Thresholds:
  Very Short: 15    ← دمج Very Short + Short
  Short: 30         ← دمج Medium
  Medium: 50        ← دمج Long + Very Long
  Long: 100         ← (غير مستخدم عملياً)

Font Multipliers:
  Very Short: 1.5
  Short: 1.0
  Medium: 0.7
  Long: 0.7         ← نفس القيمة
  Very Long: 0.7    ← نفس القيمة
```

### زيادة الدقة (مستويات أكثر)

للحصول على 7 مستويات بدلاً من 5:

```
Thresholds: 5, 10, 15, 25, 40, 60
Multipliers: 2.5, 2.0, 1.5, 1.2, 1.0, 0.7, 0.5
```

*(ملاحظة: حالياً النظام يدعم 5 مستويات فقط، لكن يمكن تعديل الكود بسهولة)*

## 🔍 استكشاف المشاكل

### المشكلة: النص لا يزال يتجاوز المساحة

**الحل:**
- قلل `font_multiplier_very_long` أكثر (مثلاً من 0.6 إلى 0.4)
- أو زد `char_threshold_long` لتطبيق التصغير مبكراً

### المشكلة: النصوص القصيرة صغيرة جداً

**الحل:**
- زد `font_multiplier_very_short` (مثلاً من 1.8 إلى 2.5)
- أو زد `char_threshold_very_short` لتطبيق التكبير على نصوص أطول

### المشكلة: أريد حجم ثابت لجميع المنتجات

**الحل:**
- عطّل ☐ `Enable Auto Font Sizing`
