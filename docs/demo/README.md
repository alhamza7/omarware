# 🎭 موقع Demo - نظام الأرشفة NBS

موقع عرض توضيحي كامل بـ HTML/CSS/JavaScript يعرض جميع مميزات نظام الأرشفة.

---

## 📁 الملفات

### 1. `index.html` - الصفحة الرئيسية ⭐
- Hero section جذاب
- إحصائيات حية (2,847 مستند)
- عرض 10 مميزات
- لوحة تحكم تفاعلية
- جدول مستندات مع 6 مستندات حقيقية

### 2. `workflow.html` - سير العمل الكامل 🔄
- Timeline تفاعلي
- 8 خطوات كاملة من الرفع للأرشفة
- مثال حي لمستند حقيقي
- رموز فك القفل
- تاريخ الإصدارات (V1 → V2)
- الإشعارات في كل خطوة

### 3. `users.html` - المستخدمون والأقسام 👥
- 4 أقسام كاملة
- 28 مستخدم (أسماء عربية)
- Managers & Users
- إحصائيات كل قسم
- بطاقات تعريفية ملونة

### 4. `features.html` - المميزات التفاعلية ✨
- بحث حي **يعمل**
- عرض نتائج البحث مع highlights
- مسح باركود (محاكاة)
- مركز إشعارات (7 إشعارات)
- سجل تدقيق كامل

### 5. `folders.html` - الإضبارات والعلاقات 📁 **جديد!**
- 4 إضبارات نموذجية (شحنة، مشروع، عميل، عقد)
- مخطط علاقات تفاعلي
- 4 مرفقات نموذجية
- هرمية كاملة (عقد → ملاحق → تعديلات)
- 3 حالات استخدام واقعية
- API endpoints كاملة
