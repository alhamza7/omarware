## 🚀 خطوات الترقية

### الطريقة 1: باستخدام السكريبت (موصى بها)

```bash
python upgrade_uom_pricelist_with_wizard.py
```

ثم أعد تشغيل Odoo:

```bash

```

### الطريقة 2: من واجهة Odoo

1. **افتح Odoo في المتصفح**
2. **فعّل Developer Mode**
   - Settings → Activate the developer mode
3. **اذهب إلى Apps**
   - Apps (في القائمة الرئيسية)
4. **ابحث عن الموديول**
   - احذف filter "Apps"
   - ابحث عن "UOM In PriceList"
5. **اضغط Upgrade**
   - سيظهر زر "Upgrade" بدلاً من "Install"

### الطريقة 3: من Command Line

```bash
python odoo-bin -c odoo.conf -u uom_in_pricelist -d lugal
```

## 📖 كيفية الاستخدام

### مثال عملي: تحديث أسعار منتج "المعشوق"

#### المشكلة الحالية:
```

الوحدة الأساسية: كغم

الأسعار الحالية:

• 0.5 كيلو: $22.00 ← غير متناسب!
• كغم: $13.25
```

#### الحل باستخدام الـ Wizard:

```
Sales → Configuration → Pricelists → حساب أسعار UoM تلقائياً
```

## ⚙️ شرح الخيارات

### 1. قائمة الأسعار (Pricelist)

القائمة التي سيتم تطبيق الحساب عليها.

```
مثال:
- SAP Price List 1 (USD)
- SAP Price List 2 (USD)
- Public Pricelist
```

### 2. المنتجات (Products)

اختياري - إذا تركته فارغاً، سيتم التطبيق على **جميع** المنتجات.

```
استخدم هذا عندما:
✓ تريد تحديث منتج واحد أو عدة منتجات محددة
✓ تريد اختبار قبل التطبيق على الجميع
✗ لا تستخدمه إذا أردت تحديث جميع المنتجات
```

### 3. مصدر السعر الأساسي (Base Price Source)

من أين يتم أخذ السعر الأساسي؟

#### Option 1: Product List Price
```
يستخدم: product.list_price
مثال: إذا سعر القائمة للكيلو = $13.25
      سيتم استخدام هذا كأساس
```

#### Option 2: Existing Pricelist Rule (موصى به)
```
يستخدم: السعر الموجود في قاعدة Pricelist
مثال: إذا كان لديك قاعدة للكيلو = $13.25
      سيتم استخدام هذا كأساس
```

💡 **توصية**: استخدم "Existing Rule" لأنه أدق.

### 4. استبدال الأسعار الموجودة (Overwrite)

هل تريد استبدال القواعد الموجودة؟

```
☑ مفعّل:
  سيتم استبدال جميع الأسعار بالأسعار المحسوبة
  
☐ غير مفعّل:
  سيتم إنشاء قواعد جديدة فقط
  القواعد الموجودة لن تتغير
```

⚠️ **تحذير**: إذا فعّلته، ستفقد الأسعار المخصصة الحالية!

### 5. الحد الأدنى للسعر (Min Price)

لن يتم إنشاء قواعد للمنتجات أقل من هذا السعر.

```
مثال: 0.01
      
لماذا؟
- لتجنب المنتجات المجانية
- لتجنب المنتجات غير السعرة بعد
```

## 🧮 كيف يتم الحساب؟

### المعادلة

```python
السعر النهائي = السعر الأساسي × (factor الهدف ÷ factor الأساس)
```

### مثال عملي

```
معطيات:
- المنتج: عطر المعشوق
- السعر الأساسي: $13.25 للكيلو
- factor الكيلو: 1.0
- factor نصف كيلو: 0.5

الحساب:
السعر لنصف كيلو = 13.25 × (0.5 ÷ 1.0)
                 = 13.25 × 0.5
                 = 6.625
                 = $6.63 (بعد التقريب)
```

### جدول الأمثلة

| الوحدة | Factor | السعر الأساسي | الحساب | السعر النهائي |
|--------|--------|---------------|--------|---------------|
| كغم | 1.000 | $13.25 | - | $13.25 |
| 0.5 كيلو | 0.500 | $13.25 | 13.25 × 0.5 | $6.63 |
| 0.25 كغم | 0.250 | $13.25 | 13.25 × 0.25 | $3.31 |
| 2 كيلو | 2.000 | $13.25 | 13.25 × 2.0 | $26.50 |

## ⚠️ تحذيرات مهمة

### 1. تأكد من صحة Factors

```
قبل استخدام Wizard، تحقق من:

✓ UoM factors صحيحة
✓ الوحدات في نفس الفئة
✓ لا توجد factors = 0

كيف تتحقق؟
Sales → Configuration → Units of Measure
```

```
لا تطبق على جميع المنتجات مباشرة!

الخطوات الصحيحة:
1. اختبر على منتج واحد

```

### 3. عمل Backup

```

1. Backup قاعدة البيانات
```

**الحل**:
```
تحقق من:
1. UoM setup للمنتج
2. Factors في uom.uom
3. السعر الأساسي > 0
```
