## 🛍️ إضافة منتجات العطور بالأسماء العربية

### الخطوة 1: افتح قائمة المنتجات

1. من القائمة الرئيسية، اضغط على: **Inventory** (المخزون)
2. اختر: **Products → Products**

### الخطوة 2: أنشئ منتج جديد أو عدّل موجود

#### لإنشاء منتج جديد:
1. اضغط **Create** (إنشاء)

#### لتعديل منتج موجود:
1. اضغط على أي منتج من القائمة

### الخطوة 3: املأ معلومات المنتج

```

│ Product Name: Vanilla Absolute          │ (الاسم بالإنجليزية)
│ ↓↓↓ الحقل الجديد ↓↓↓                   │
│ Arabic Name: فانيليا مطلقة              │ ← هذا الحقل الجديد!
│                                          │
│ Internal Reference: PF001                │
│ Sales Price: 45.00                       │
│ Cost: 30.00                              │
│ Product Type: Storable Product           │
└─────────────────────────────────────────┘
```

### الخطوة 4: احفظ المنتج
اضغط **Save** (حفظ) ✅

## 💰 استخدام POS (نقطة البيع)

### الخطوة 1: افتح POS

1. من القائمة الرئيسية، اضغط: **Point of Sale**
2. اختر نقطة البيع الخاصة بك
3. اضغط **New Session** (جلسة جديدة)

### الخطوة 2: شاهد التحسينات!

الآن في واجهة POS ستشاهد:

```
╔════════════════════════════════════╗
║  Vanilla Absolute                  ║
║  فانيليا مطلقة      ← الاسم العربي ║
║  ────────────────────────────────  ║
║  $45.00             ← السعر بالدولار ║
║  58,500 IQD    ← السعر بالدينار! NEW ║
╚════════════════════════════════════╝
```

### الخطوة 3: إضافة منتج للطلب

1. اضغط على المنتج
2. سيضاف للطلب تلقائياً
3. ستشاهد الإجمالي بالدولار والدينار

### الخطوة 4: إتمام البيع

1. اضغط **Payment** (الدفع)
2. اختر طريقة الدفع
3. اضغط **Validate** (تأكيد)
4. ✅ تم إتمام البيع!

## 🔢 حساب الأسعار

سعر التحويل الافتراضي: **1 دولار = 1,300 دينار عراقي**

أمثلة:
- $45.00 → **58,500 IQD**
- $125.00 → **162,500 IQD**
- $68.50 → **89,050 IQD**
- $280.00 → **364,000 IQD**

## ⚙️ تغيير سعر الصرف (اختياري)

إذا أردت تغيير السعر من 1,300 إلى رقم آخر:

1. أوقف Odoo (Ctrl+C في نافذة الأوامر)

2. افتح الملف:
   ```
   L:\Lugal-ai\addons\pos_perfume_custom\static\src\app\perfume_enhancements.js
   ```

3. في السطر 14، غيّر الرقم:
   ```javascript
   const iqdAmount = amount * 1300; // غيّر 1300 للسعر المطلوب
   ```

4. احفظ الملف

5. شغّل Odoo مرة أخرى:
   ```bash
   cd L:\Lugal-ai
   python odoo-bin -c odoo.conf
   ```

## 📱 سير العمل الكامل

### سيناريو: بيع عطور لعميل

7. **تضغط Validate** ✅

8. **تطبع الفاتورة** 🖨️

9. **انتهى!** 🎉

## ❓ الأسئلة الشائعة

### س1: هل يمكن تغيير العملة إلى غير الدينار؟
**ج:** نعم! عدّل في ملف `perfume_enhancements.js`

### س2: هل الأسماء العربية إجبارية؟
**ج:** لا، اختيارية. إذا لم تضف اسم عربي، لن يظهر شيء إضافي.

**ج:** لا، التحسينات فقط في POS.

### س4: كيف أحذف الوحدة إذا أردت؟
**ج:** من Settings → Apps → ابحث عن pos_perfume_custom → Uninstall
