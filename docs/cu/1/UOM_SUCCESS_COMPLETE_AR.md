## 📊 **أمثلة عملية:**

### **مجموعة: فل بلاستك (8 وحدات)**
```
المجموعة: فل بلاستك (Entry: 9)
Base UoM: كغم (Entry: 6)

الوحدات:
   • 0.5 كيلو      → factor: 0.500000  (نصف كيلو)
   • 25 كغم        → factor: 25.000000 (25 كيلو)
   • 100 كغم       → factor: 100.000000 (100 كيلو)
   • 500 كغم       → factor: 500.000000 (500 كيلو)
   • 1000 كغم      → factor: 1000.000000 (طن)
   ... إلخ
```

### **مجموعة: باكيت 100 حبة (2 وحدات)**
```
المجموعة: باكيت 100 حبة (Entry: 165)
Base UoM: باكيت (Entry: 20)

الوحدات:
   • قطعه         → مرتبطة
   • باكيت        → مرتبطة
```

### **مثال التحويل:**
```
1000 كغم (factor: 1000.000000)
   = 1000 × الوحدة الأساسية
   
0.050 غم (factor: 0.050000)
   = 0.05 × الوحدة الأساسية
```
