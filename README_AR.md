# 📦 نظام الأرشفة NBS

**نظام أرشفة إلكتروني للمستندات لشركة نور النبراس - شركة سلع استهلاكية**

نظام إدارة مستندات متكامل وجاهز للإنتاج مبني على **Odoo 19** مع واجهة أمامية حديثة بـ **React**.

---

## 🌟 المميزات

### الوظائف الأساسية
- ✅ **إدارة المستندات حسب الأقسام** مع عزل تام
- ✅ **التحكم بالصلاحيات** (مدير، مشرف، مستخدم)
- ✅ **نظام الإصدارات** مع سجل كامل
- ✅ **سير عمل طلبات التعديل** مع موافقة المشرف
- ✅ **رموز فك القفل لمرة واحدة** للتعديل الآمن
- ✅ **توليد الباركود** والبحث به
- ✅ **بحث متقدم** مع فلاتر
- ✅ **سجل التدقيق** لجميع العمليات
- ✅ **إشعارات فورية**
- ✅ **ثنائي اللغة** (عربي مع RTL + إنجليزي)
- ✅ **لا حذف نهائي** - أرشفة فقط

### المميزات التقنية
- ✅ **التعرف الضوئي OCR** جاهز (Tesseract للعربية والإنجليزية)
- ✅ **تكامل OpenSearch** للبحث في المحتوى
- ✅ **REST API** (JSON-RPC)
- ✅ **نسخ احتياطي تلقائي**

## 🎯 الاستخدام

### إدارة المستندات

1. **رفع مستند**:
   - اذهب إلى "المستندات" → "رفع"
   - اختر القسم ونوع المستند
   - املأ البيانات الوصفية وارفع الملف
   - يتم **قفل** المستند تلقائياً بعد الرفع

2. **طلب تعديل**:
   - افتح المستند
   - اضغط "طلب تعديل"
   - قدم السبب
   - يستلم المشرف إشعاراً

3. **الموافقة على التعديل** (للمشرفين فقط):
   - اذهب إلى "طلبات التعديل"
   - راجع الطلبات المعلقة
   - وافق أو ارفض
   - يُنشئ النظام رمز فك قفل لمرة واحدة

4. **رفع نسخة جديدة**:
   - استخدم رمز فك القفل من الموافقة
   - ارفع الملف الجديد
   - يتم حفظ النسخ السابقة
   - يُقفل المستند مجدداً

### البحث

- **أساسي**: ابحث بالعنوان، الباركود، أو البيانات الوصفية
- **باركود**: مسح أو إدخال الباركود يدوياً
- **متقدم**: فلتر بالقسم، النوع، نطاق التاريخ
- **المحتوى** (يتطلب OpenSearch): ابحث داخل المستندات

### النسخ الاحتياطي والاستعادة

**نسخ احتياطي**:
```powershell
.\scripts\backup.ps1
```

**استعادة**:
```powershell
.\scripts\restore.ps1 -BackupPath "D:\nbs_backups\nbs_archive_backup_20251217_120000"
```

## 👥 الأدوار

### المدير (Admin)
- صلاحية كاملة على النظام
- إدارة الأقسام وأنواع المستندات
- عرض جميع سجلات التدقيق
- أرشفة/إلغاء أرشفة المستندات

### المشرف (Manager) - لكل قسم
- الموافقة/رفض طلبات التعديل
- أرشفة/إلغاء أرشفة المستندات في قسمهم
- عرض مستندات القسم
- إدارة الوسوم

### المستخدم (User) - لكل قسم
- رفع المستندات
- عرض مستندات قسمهم
- طلب تعديل المستندات
- تحميل المستندات
