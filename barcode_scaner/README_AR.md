# 📦 نظام إدارة الجرد - النسخة الكاملة

## 🚀 البدء السريع

### 1. التثبيت
```bash
npm install
```

### 2. إعداد SAP
```bash
node create_env.js
```
ثم عدّل ملف `.env` بإعدادات SAP الخاصة بك.

### 3. التشغيل
```bash
node src/server.js
```

### 4. الوصول
```
http://localhost:3000
```

## 🎛️ لوحة التحكم (Admin)

للمدراء فقط: `http://localhost:3000/admin`

**الوظائف:**
- 📊 إحصائيات النظام
- 📥 استيراد ملفات Excel
- 🗄️ إدارة البيانات
- 🔌 اختبار اتصال SAP
- 🗑️ حذف البيانات

---

## 📥 التصدير

من صفحة التقارير (`/reports`):
- Admin فقط يمكنه التصدير
- يجلب كميات SAP الحالية
- يحسب الفرق تلقائياً
- يضيف اسم المستخدم

---

## 📤 الاستيراد

من لوحة التحكم:
- اسحب ملفات Excel وأفلتها
- أو انقر واختر الملفات
- دعم ملفات متعددة دفعة واحدة

**التنسيق المطلوب:**
```
| ItemCode | ItemName | Barcode | UOM |
```

---

## 🔧 إعدادات SAP

في ملف `.env`:

```env
SAP_ENABLED=true
SAP_SERVICE_LAYER_URL=https://192.168.15.50:50000/b1s/v1
SAP_COMPANY_DB=NBS_LIVE_NEW
SAP_USERNAME=manager
SAP_PASSWORD=na54321
```
