# 📦 النسخة v7 - التحديثات الشاملة

## 🆕 التحديثات الجديدة

### 1. ✅ إصلاح Dialog الوحدات المتعددة في البحث اليدوي
**المشكلة:** عند البحث اليدوي واختيار عنصر يحتوي على وحدة قياس مثل "درزن"، كان يظهر Dialog عادي بدلاً من Dialog الوحدات المتعددة.

**الحل:**
- إضافة فحص لنوع الوحدة في دالة `_onSelectSearchResult`
- استخدام `_multiUnitDialog` للعناصر ذات الوحدات المتعددة (قطعة، باكيت، سيت، درزن، كارتون)
- الآن يعمل Dialog الوحدات المتعددة سواءً عند المسح بالكاميرا أو البحث اليدوي

### 2. 🔢 إزالة الحسابات التلقائية للوحدات
**المشكلة:** كان النظام يحسب تلقائياً: 1 درزن = 12 قطعة، 1 كارتون = 144 قطعة، لكن عدد القطع يختلف من كارتون لآخر.

**الحل:**
- إزالة التوضيحات من الحقول (مثل "1 درزن = 12 قطعة")
- إزالة عرض الإجمالي المحسوب تلقائياً
- تعديل السيرفر ليحفظ البيانات كما هي بدون جمع تلقائي
- الآن يتم تسجيل كل وحدة بشكل منفصل في الإكسل:
  - `Qty_Pieces`: عدد القطع
  - `Qty_Dozen`: عدد الدرزنات
  - `Qty_Carton`: عدد الكراتين
  - `Qty_Total`: القطع فقط (للتوافق مع النظام)

### 3. 👤 عرض اسم المستخدم في شريط التطبيق
**الميزة الجديدة:**
- إضافة دالة `getUserInfo()` في API للحصول على معلومات المستخدم
- عرض اسم المستخدم في AppBar بجانب عنوان "الجرد"
- تصميم جذاب مع أيقونة شخص وخلفية شفافة
- يتم تحميل الاسم تلقائياً عند فتح التطبيق

### 4. 🌐 إضافة Dialog الوحدات المتعددة لنسخة الويب
**الميزة الجديدة:**
- إضافة نفس Dialog الوحدات المتعددة لنسخة الويب
- يظهر تلقائياً للعناصر ذات وحدات القياس المتعددة
- تصميم متجاوب يعمل على الموبايل والديسكتوب
- حقول منفصلة: قطعة/باكيت/سيت، درزن، كارتون
- حفظ البيانات منفصلة بدون حسابات تلقائية

   - إصلاح `_onSelectSearchResult` لدعم Dialog الوحدات المتعددة

   - إضافة دالة `_loadUsername()` لتحميل اسم المستخدم

### السيرفر:
3. `src/server.js`
   - تعديل حفظ الكميات لإزالة الحسابات التلقائية (×12 و ×144)
   - البيانات تُحفظ كما هي في الأعمدة المنفصلة

### الويب:
4. `public/app.js`
   - إضافة دالة `getUnitType()` لتحديد نوع الوحدة
   - إضافة دالة `getUnitLabel()` للحصول على اسم الوحدة بالعربي
   - إضافة دالة `openMultiUnitDialog()` لعرض Dialog الوحدات المتعددة
   - تعديل `openCountDialog()` لاستخدام Dialog المناسب حسب نوع الوحدة

## 📊 تصدير الإكسل

التقرير المُصدّر يحتوي على الأعمدة التالية:
- `Warehouse`: رقم المخزن
- `ItemCode`: كود الصنف
- `ItemName`: اسم الصنف
- `Barcode`: الباركود
- `UOM`: وحدة القياس
- **`Qty_Pieces`**: عدد القطع/الباكيت/السيت ✨
- **`Qty_Dozen`**: عدد الدرزنات ✨
- **`Qty_Carton`**: عدد الكراتين ✨
- `Qty_Total`: الإجمالي (القطع فقط)
- `CountedQty`: الكمية المجرودة (الحقل القديم)
- `SAP_AtCount`: كمية SAP وقت الجرد
- `SAP_Current`: كمية SAP الحالية
- `Difference`: الفرق
- `UpdatedQty`: الكمية المحدثة
- `LastUser`: آخر مستخدم
- `LastTime`: آخر وقت
- `CountEntries`: عدد مرات الجرد
- `Modified`: هل تم التعديل

## 🚀 التثبيت والاستخدام

### تطبيق الموبايل:
1. قم بإلغاء تثبيت النسخة القديمة (إن وجدت)
2. ثبّت `inventory_app_v7_final.apk`
3. سجّل دخولك بحسابك

1. تأكد من تشغيل السيرفر: `npm run dev`
2. افتح المتصفح على `http://localhost:3000/inventory`
3. سجّل دخولك
4. عند اختيار عنصر بوحدة متعددة، سيظهر Dialog الوحدات المتعددة تلقائياً
