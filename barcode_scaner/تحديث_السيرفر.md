## 🎯 **إذا لم تظهر وحدة القياس:**

### **1. حدّث الصفحة بقوة:**
```
اضغط: Ctrl + Shift + R
أو: Ctrl + F5
```

### **2. امسح الـ Cache:**
```
F12 → Application → Clear storage → Clear site data
```

### **3. تأكد من تحديث API:**
افتح Console (F12) ونفذ:
```javascript
fetch('/api/items/search?q=14145')
  .then(r => r.json())
  .then(d => {
    console.log('النتيجة:', d.items[0]);
    if (d.items[0]?.uom) {
      console.log('✅ وحدة القياس موجودة:', d.items[0].uom);
    } else {
      console.log('❌ وحدة القياس غير موجودة');
    }
  });
```

## 💡 **نصيحة:**

إذا كنت تستخدم الموبايل للاتصال بالسيرفر على نفس الشبكة:

1. تأكد من IP السيرفر:
```powershell
ipconfig | Select-String "IPv4"
```

2. عدّل في الموبايل (إذا لزم):
```
mobile_app_runner/lib/config.dart
```
