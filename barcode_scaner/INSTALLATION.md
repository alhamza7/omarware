### 3️⃣ تكوين SAP (دقيقة واحدة - اختياري)

#### إذا كنت تريد تفعيل SAP:

```bash
# انسخ ملف النموذج
cp env.example .env

# افتح .env وعدّل البيانات
nano .env  # أو استخدم محرر نصوص آخر
```

**عدّل هذه القيم في `.env`:**

```env
# تفعيل SAP
SAP_ENABLED=true

# عنوان Service Layer
SAP_SERVICE_LAYER_URL=https://192.168.1.100:50000/b1s/v1

# بيانات الشركة
SAP_COMPANY_DB=SBODEMOUS

# بيانات الدخول
SAP_USERNAME=manager
SAP_PASSWORD=your_password

# أكواد المخازن (اختياري)
SAP_WH_01=WH01
SAP_WH_02=WH02
# ... إلخ
```

#### إذا لم تكن تريد SAP (العمل بدون SAP):

```bash
# لا تفعل شيئاً!
# النظام يعمل بشكل طبيعي بدون SAP
```

## ✅ اختبار النظام

### اختبار السيرفر:

```bash
# افتح في المتصفح
http://localhost:3000
```

### اختبار SAP:

```bash
# اختبر حالة الاتصال
curl http://localhost:3000/api/sap/status

# يجب أن ترى:
{
  "enabled": true,
  "connected": true
}
```

### اختبار API:

```bash
# سجل الدخول أولاً واحصل على TOKEN
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# استخدم TOKEN للاختبار
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3000/api/sap/item-quantity/ITEM001
```

## 🐛 المشاكل الشائعة وحلولها

### ❌ المشكلة: `npm install` يفشل

**الحل:**
```bash
# احذف المجلد وأعد المحاولة
rm -rf node_modules
rm package-lock.json
npm install
```

---

### ❌ المشكلة: SAP لا يتصل

**الحل:**
```bash
# تأكد من:
1. SAP_ENABLED=true في .env
2. عنوان Service Layer صحيح
3. المنفذ 50000 مفتوح
4. بيانات الدخول صحيحة
5. الشبكة تسمح بالاتصال

# اختبر الاتصال يدوياً:
ping your-sap-server
telnet your-sap-server 50000
```

---

### ❌ المشكلة: Flutter Build يفشل

**الحل:**
```bash
# حدّث Flutter
flutter upgrade

# نظف ثم أعد البناء
flutter clean
flutter pub get
flutter build apk --release
```
