## ✨ أمثلة الاستخدام

### مثال 1: عند المسح الضوئي

```javascript
// المستخدم يمسح باركود
→ النظام يجلب من قاعدة البيانات المحلية
→ النظام يجلب من SAP تلقائياً
→ يعرض:
  - معلومات الصنف
  - آخر جرد
  - كمية SAP (الموجود، المحجوز، المتاح)
→ المستخدم يدخل الكمية الفعلية
→ حفظ ✅
```

### مثال 2: API Request

```bash
curl -H "Authorization: Bearer TOKEN" \
  http://localhost:3000/api/items/by-code/ITEM001

# Response:
{
  "item": { ... },
  "lastCount": { "qty": 145, ... },
  "sapQuantity": {
    "quantity": 150,
    "committed": 20,
    "available": 130
  }
}
```

## 🔄 سير العمل

```
📱 المستخدم
    ↓
    ↓ (1) مسح باركود/بحث
    ↓
🖥️  السيرفر (Node.js)
    ↓
    ↓ (2) جلب من DB المحلية + جلب من SAP
    ↓
🏢 SAP B1 Service Layer
    ↓
    ↓ (3) إرجاع الكميات
    ↓
🖥️  السيرفر
    ↓
    ↓ (4) دمج البيانات
    ↓
📱 عرض في الواجهة
    ↓
    ↓ (5) إدخال الكمية الفعلية
    ↓
💾 حفظ في DB
```
