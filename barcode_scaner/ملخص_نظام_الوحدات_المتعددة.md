## 🎯 كيفية العمل

### 🔄 سير العمل:

```
1️⃣ المستخدم يمسح الباركود
   └─ النظام يتحقق من نوع الوحدة (UOM)

2️⃣ إذا كان نوع مدعوم (قطعة/باكيت/سيت):
   ├─ يعرض Dialog الوحدات المتعددة
   ├─ المستخدم يدخل: قطعة، درزن، كارتون
   ├─ النظام يحسب الإجمالي تلقائياً
   │  الإجمالي = قطعة + (درزن × 12) + (كارتون × 144)
   └─ عند الحفظ: يرسل كل التفاصيل للسيرفر

3️⃣ إذا كان نوع آخر:
   ├─ يعرض Dialog عادي (حقل واحد)
   └─ المستخدم يدخل الكمية مباشرة

4️⃣ السيرفر:
   ├─ يستقبل البيانات
   ├─ يحفظ في قاعدة البيانات (مع التفاصيل)
   └─ يرجع التأكيد

5️⃣ التقارير:
   ├─ تجلب البيانات مع التفاصيل
   ├─ تعرض في جدول الويب
   └─ تصدّر في Excel مع جميع الأعمدة

6️⃣ حسابات SAP:
   ├─ تتم على Qty_Total فقط
   ├─ الفرق = Qty_Total - SAP_Available
   └─ لا عمليات على الوحدات الفردية
```

## 📐 معادلات التحويل

### القاعدة الأساسية:
```
1 درزن = 12 وحدة أساسية
1 كارتون = 12 درزن = 144 وحدة أساسية
```

### أمثلة حسابية:

**مثال 1:**
```
قطعة: 5
درزن: 2
كارتون: 1

الإجمالي = 5 + (2 × 12) + (1 × 144)
         = 5 + 24 + 144
         = 173 قطعة ✓
```

**مثال 2:**
```
باكيت: 3
درزن: 1
كارتون: 0

الإجمالي = 3 + (1 × 12) + (0 × 144)
         = 3 + 12 + 0
         = 15 باكيت ✓
```

**مثال 3:**
```
سيت: 0
درزن: 5
كارتون: 2

الإجمالي = 0 + (5 × 12) + (2 × 144)
         = 0 + 60 + 288
         = 348 سيت ✓
```
