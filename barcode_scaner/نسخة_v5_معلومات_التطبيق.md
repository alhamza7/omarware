## 📥 التثبيت

### الطريقة 1: التثبيت المباشر
1. انقل الملف `inventory_app_v5_sap_available_only.apk` إلى الهاتف
2. افتح الملف من مدير الملفات
3. اضغط "تثبيت"
4. إذا ظهرت رسالة "مصدر غير معروف"، اسمح بالتثبيت

### الطريقة 2: عبر ADB
```bash
adb install inventory_app_v5_sap_available_only.apk
```

### الطريقة 3: التحديث فوق النسخة القديمة
- يمكنك التثبيت مباشرة فوق النسخة القديمة
- **ملاحظة:** البيانات محفوظة على السيرفر، ليست على التطبيق

## 🔄 الترقية من نسخة سابقة

### إذا كان لديك v4 أو أقل:
1. يمكنك التثبيت مباشرة فوق النسخة القديمة
2. لا حاجة لحذف النسخة القديمة
3. البيانات لن تضيع

### إلغاء التثبيت:
- ليس ضرورياً
- إذا أردت إلغاء التثبيت: الإعدادات > التطبيقات > inventory_app > إلغاء التثبيت

## ⚙️ الإعدادات المطلوبة

### عنوان السيرفر:
يجب تعديل عنوان السيرفر في ملف التكوين قبل البناء:

**الملف:** `mobile_app_runner/lib/config.dart`

```dart
class AppConfig {
  static const String baseUrl = 'http://YOUR_SERVER_IP:3000';
}
```

### إذا كنت تريد تغيير عنوان السيرفر:
1. عدل الملف `mobile_app_runner/lib/config.dart`
2. شغل الأمر:
```bash
cd mobile_app_runner
flutter build apk --release
```
