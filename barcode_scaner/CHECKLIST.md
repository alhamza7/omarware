## 🧪 اختبارات API

### Test 1: حالة SAP
```bash
curl http://localhost:3000/api/sap/status
```

**المتوقع:**
```json
{
  "enabled": true,
  "connected": true,
  "serviceLayerUrl": "https://..."
}
```

- [ ] `enabled: true`
- [ ] `connected: true`
- [ ] عنوان Service Layer يظهر

---

### Test 2: تسجيل الدخول
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

**المتوقع:**
```json
{
  "token": "eyJ...",
  "user": {...},
  "warehouse_id": 1
}
```

- [ ] token موجود
- [ ] user data صحيح
- [ ] warehouse_id موجود

---

### Test 3: جلب كمية من SAP (بكود الصنف)

احصل على TOKEN من Test 2، ثم:

```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3000/api/sap/item-quantity/ITEM001
```

**المتوقع:**
```json
{
  "ok": true,
  "data": {
    "itemCode": "ITEM001",
    "itemName": "...",
    "warehouseCode": "WH01",
    "quantity": 150,
    "committed": 20,
    "available": 130
  }
}
```

- [ ] `ok: true`
- [ ] البيانات تظهر بشكل صحيح
- [ ] الكميات منطقية

---

### Test 4: جلب كمية من SAP (بالباركود)

### Test 5: جلب صنف مع كمية SAP
