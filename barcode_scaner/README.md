# 📦 نظام الجرد بالباركود - Barcode Inventory System

نظام متكامل لإدارة الجرد باستخدام الباركود مع دعم **تطبيق موبايل** و **واجهة ويب** + **تكامل مع SAP Business One**

---

## ✨ الميزات الرئيسية

### 🎯 ميزات الجرد
- ✅ **مسح الباركود/QR Code** بسرعة فائقة (محسّن 3x)
- ✅ **البحث اليدوي** عن الأصناف
- ✅ **دعم 18 مخزن** مع إمكانية التبديل بينها
- ✅ **تتبع آخر جرد** لكل صنف
- ✅ **دعم وحدات القياس (UOM)** مختلفة
- ✅ **إضافة كميات إضافية** أو تعديل الجرد

### 🔗 التكامل مع SAP B1 (جديد!)
- ☁️ **جلب الكميات من SAP لحظياً** عند الجرد
- 📊 **عرض الكميات المحجوزة والمتاحة** من SAP
- 🔄 **مطابقة فورية** بين الجرد الفعلي وكمية SAP
- 🎯 **دعم البحث بالباركود وكود الصنف** من SAP

### 📱 تطبيق الموبايل
- 📲 **تطبيق Flutter** للأندرويد
- 📷 **ماسح ضوئي سريع** (500ms استجابة)
- 🔦 **دعم الفلاش** للإضاءة المنخفضة
- 📶 **يعمل أوفلاين** (بدون SAP)

### 🌐 واجهة الويب
- 💻 **لوحة تحكم ويب كاملة**
- 📊 **تقارير مفصلة** مع إمكانية التصدير لـ Excel
- 🔍 **بحث متقدم** بالفلاتر
- 📈 **إحصائيات شاملة** للجرد

## 🚀 التشغيل السريع

### 1️⃣ تثبيت الحزم

```bash
npm install
```

### 2️⃣ استيراد البيانات

```bash
npm run seed:import
```

### 3️⃣ تكوين SAP (اختياري)

انسخ ملف النموذج:
```bash
cp env.example .env
```

ثم عدّل `.env`:
```env
SAP_ENABLED=true
SAP_SERVICE_LAYER_URL=https://your-sap-server:50000/b1s/v1
SAP_COMPANY_DB=YOUR_DB
SAP_USERNAME=manager
SAP_PASSWORD=your_password
```

> **ملاحظة:** النظام يعمل بشكل طبيعي حتى لو كان SAP معطلاً!

### 4️⃣ تشغيل السيرفر

```bash
npm run dev
```

افتح المتصفح على: **http://localhost:3000**

## 🔧 APIs المتاحة

### Inventory APIs
```
POST   /api/auth/login          # تسجيل الدخول
GET    /api/me                  # معلومات المستخدم
GET    /api/items/search        # البحث عن الأصناف
GET    /api/items/by-code/:code # جلب صنف بالكود
POST   /api/counts              # حفظ الجرد
GET    /api/reports/summary     # تقرير الجرد
GET    /api/reports/export.xlsx # تصدير لـ Excel
```

### SAP APIs (جديد!)
```
GET    /api/sap/status                    # حالة الاتصال
GET    /api/sap/item-quantity/:itemCode   # جلب كمية من SAP
GET    /api/sap/item-by-barcode/:barcode  # جلب صنف بالباركود
```
