# 📦 نظام الوحدات المتعددة - المواصفات الكاملة

## 🎯 الهدف

إضافة نظام وحدات متعددة للجرد بحيث يمكن إدخال الكمية بأكثر من وحدة قياس حسب نوع الصنف.

---

## 📋 أنواع الأصناف والوحدات

### 1. أصناف القطع (قطعة/قطعه/Piece/PCS):
```
الحقول:
├─ قطعة: ___ 
├─ درزن: ___ (1 درزن = 12 قطعة)
└─ كارتون: ___ (1 كارتون = 12 درزن = 144 قطعة)

الحساب:
الإجمالي = قطعة + (درزن × 12) + (كارتون × 144)
```

### 2. أصناف الباكيت (باكيت/Packet):
```
الحقول:
├─ باكيت: ___
├─ درزن: ___ (1 درزن = 12 باكيت)
└─ كارتون: ___ (1 كارتون = 12 درزن)

الحساب:
الإجمالي = باكيت + (درزن × 12) + (كارتون × 144)
```

### 3. أصناف السيت (سيت/Set):
```
الحقول:
├─ سيت: ___
├─ درزن: ___ (1 درزن = 12 سيت)
└─ كارتون: ___ (1 كارتون = 12 درزن)

الحساب:
الإجمالي = سيت + (درزن × 12) + (كارتون × 144)
```

### 4. أصناف الدرزن (Dozen):
```
الحقول:
├─ درزن: ___
└─ كارتون: ___ (1 كارتون = 12 درزن)

الحساب:
الإجمالي بالدرزن = درزن + (كارتون × 12)
```

### 5. باقي الأصناف (كغ، لتر، متر...):
```
حقل واحد:
└─ الكمية: ___ (بالوحدة الأساسية)
```

## 🗄️ قاعدة البيانات

### جدول `counts` - الأعمدة الجديدة:

| العمود | النوع | الوصف |
|--------|------|-------|
| `qty_pieces` | REAL | عدد القطع/الباكيت/السيت |
| `qty_dozen` | REAL | عدد الدرزن |
| `qty_carton` | REAL | عدد الكراتين |
| `qty_total` | REAL | الإجمالي بالوحدة الأساسية |
| `qty` | REAL | القديم - للتوافق (= qty_total) |

## 🔧 التطبيق (Flutter)

### الكود الذكي لتحديد نوع الصنف:

```dart
String _getUnitType(String? uom) {
  if (uom == null || uom.isEmpty) return 'default';
  
  final normalized = uom.toLowerCase().trim();
  
  // قطعة
  if (normalized == 'قطعة' || normalized == 'قطعه' || 
      normalized == 'piece' || normalized == 'pcs') {
    return 'piece';
  }
  
  // باكيت
  if (normalized == 'باكيت' || normalized == 'packet' || normalized == 'pack') {
    return 'packet';
  }
  
  // سيت
  if (normalized == 'سيت' || normalized == 'set') {
    return 'set';
  }
  
  // درزن
  if (normalized == 'درزن' || normalized == 'dozen') {
    return 'dozen';
  }
  
  // كارتون
  if (normalized == 'كارتون' || normalized == 'carton') {
    return 'carton';
  }
  
  return 'default';
}
```

### Dialog الوحدات المتعددة:

```dart
Future<Map<String, double>?> _multiUnitDialog({
  required String code,
  required String name,
  required String unitType, // 'piece', 'packet', 'set', 'dozen'
  Map<String, dynamic>? sapQuantity,
}) async {
  final piecesController = TextEditingController();
  final dozenController = TextEditingController();
  final cartonController = TextEditingController();
  
  return showDialog<Map<String, double>>(
    context: context,
    builder: (ctx) => AlertDialog(
      title: Text('جرد: $name'),
      content: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Text('كود: $code'),
          
          // حقل القطعة/الباكيت/السيت
          TextField(
            controller: piecesController,
            keyboardType: TextInputType.number,
            decoration: InputDecoration(
              labelText: _getUnitLabel(unitType),
            ),
          ),
          
          // حقل الدرزن
          TextField(
            controller: dozenController,
            keyboardType: TextInputType.number,
            decoration: InputDecoration(
              labelText: 'درزن (1 درزن = 12 ${_getUnitLabel(unitType)})',
            ),
          ),
          
          // حقل الكارتون
          TextField(
            controller: cartonController,
            keyboardType: TextInputType.number,
            decoration: InputDecoration(
              labelText: 'كارتون (1 كارتون = 144 ${_getUnitLabel(unitType)})',
            ),
          ),
          
          // عرض الإجمالي
          ValueListenableBuilder(
            // ... حساب الإجمالي تلقائياً
          ),
        ],
      ),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(ctx, null),
          child: Text('إلغاء'),
        ),
        FilledButton(
          onPressed: () {
            final pieces = double.tryParse(piecesController.text) ?? 0;
            final dozen = double.tryParse(dozenController.text) ?? 0;
            final carton = double.tryParse(cartonController.text) ?? 0;
            
            Navigator.pop(ctx, {
              'pieces': pieces,
              'dozen': dozen,
              'carton': carton,
              'total': pieces + (dozen * 12) + (carton * 144),
            });
          },
          child: Text('حفظ'),
        ),
      ],
    ),
  );
}
```

## 🌐 API Endpoint

### POST `/api/counts`

**Request Body:**
```json
{
  "item_id": 123,
  "qty": 173,  // اختياري - للتوافق
  "qty_pieces": 5,
  "qty_dozen": 2,
  "qty_carton": 1,
  "note": "ملاحظة",
  "sap_qty": 150,
  "sap_available": 140
}
```

**Response:**
```json
{
  "ok": true,
  "id": 456,
  "qty_total": 173
}
```

**الحساب في السيرفر:**
```javascript
qty_total = qty_pieces + (qty_dozen * 12) + (qty_carton * 144)
// 5 + (2 × 12) + (1 × 144) = 5 + 24 + 144 = 173
```

## 📱 سير العمل

```
1. المستخدم يمسح/يبحث عن صنف
   └─ النظام يحدد نوع الوحدة من UOM

2. إذا كان نوع قطعة/باكيت/سيت:
   ├─ يظهر dialog الوحدات المتعددة
   ├─ المستخدم يدخل: قطعة، درزن، كارتون
   ├─ النظام يحسب الإجمالي تلقائياً
   └─ عند الحفظ: يرسل كل الوحدات

3. إذا كان نوع آخر:
   ├─ يظهر dialog عادي (حقل واحد)
   └─ المستخدم يدخل الكمية مباشرة

4. السيرفر:
   ├─ يستقبل البيانات
   ├─ يحسب qty_total
   ├─ يحفظ في قاعدة البيانات
   └─ يرجع التأكيد

5. التقارير:
   ├─ تعرض التفاصيل (قطعة، درزن، كارتون)
   └─ Excel يحتوي على جميع الأعمدة
```
