## 🔄 الملفات المعدلة

### Backend
1. **`src/server.js`**
   - إضافة endpoints جديدة:
     - `GET /api/sap/item-quantity/:itemCode`
     - `GET /api/sap/item-by-barcode/:barcode`
     - `GET /api/sap/status`
   - تحديث `GET /api/items/by-code/:code` لتضمين كميات SAP
   - تحميل `dotenv` لمتغيرات البيئة

2. **`package.json`**
   - إضافة `axios` للاتصال بـ SAP

### Frontend (Flutter)
3. **`mobile_app_runner/lib/api.dart`**
   - إضافة دوال:
     - `getSAPItemQuantity()`
     - `getSAPItemByBarcode()`
     - `getSAPStatus()`

4. **`mobile_app_runner/lib/screens/inventory_screen.dart`**
   - عرض كمية SAP في dialog إدخال الكمية
   - عرض كمية SAP عند المسح الضوئي
   - عرض كمية SAP عند البحث اليدوي
   - تصميم جميل لعرض معلومات SAP (الكمية الموجودة، المحجوزة، المتاحة)

## 🎯 الميزات الجديدة

### 1. جلب الكمية من SAP لحظياً
عند مسح الباركود أو البحث عن صنف، يتم:
- ✅ جلب الكمية الموجودة في SAP
- ✅ عرض الكمية المحجوزة (Committed)
- ✅ عرض الكمية المتاحة (Available)
- ✅ عرضها في واجهة جميلة ومنظمة

### 2. دعم البحث المتعدد
- البحث بكود الصنف (ItemCode)
- البحث بالباركود (Barcode)
- البحث في المخزن المحدد فقط

### 3. إدارة الجلسة الذكية
- تسجيل دخول تلقائي
- تجديد الجلسة قبل انتهائها
- إعادة الاتصال التلقائي عند انقطاع الجلسة

### 4. دعم 18 مخزن
مطابقة كاملة لجميع المخازن (1-18) مع أكواد SAP

## 🚀 كيفية الاستخدام

### خطوة 1: تثبيت الحزم
```bash
npm install
```

### خطوة 2: إعداد SAP
انسخ `env.example` إلى `.env` وعدل البيانات:

```env
SAP_ENABLED=true
SAP_SERVICE_LAYER_URL=https://192.168.1.100:50000/b1s/v1
SAP_COMPANY_DB=SBODEMOUS
SAP_USERNAME=manager
SAP_PASSWORD=your_password

# مطابقة المخازن
SAP_WH_01=WH01
SAP_WH_02=WH02
# ... إلخ
```

### خطوة 3: تشغيل السيرفر
```bash
npm run dev
```

### خطوة 4: بناء تطبيق الموبايل
```bash
cd mobile_app_runner
flutter clean
flutter build apk --release
```
