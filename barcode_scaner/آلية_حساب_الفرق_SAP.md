# 📊 آلية حساب الفرق والتحديث في SAP

## 🎯 الطريقة الصحيحة (المطبقة الآن)

---

## 📋 المثال العملي:

### صنف: ITEM001 | المخزن: 1

---

### 🕐 المرحلة 1: وقت الجرد (10 صباحاً)

```
الموظف يجرد الصنف:
- الكمية المجرودة: 100 قطعة
- SAP Available (وقت الجرد): 80 قطعة

يتم حفظ في قاعدة البيانات:
├─ qty: 100
├─ sap_available: 80 ✅
└─ الفرق الفعلي: 100 - 80 = +20 قطعة
```

**المعنى:** الموظف وجد 20 قطعة زيادة عن SAP

---

### ⏰ خلال اليوم (حركات في SAP)

```
بعد الجرد، حدثت حركات في SAP:
- مبيعات: -5 قطع
- مشتريات: +10 قطع

SAP Available الآن أصبح:
80 - 5 + 10 = 85 قطعة ✅
```

---

### 📥 المرحلة 2: وقت التصدير (5 مساءً)

```
المدير يصدر ملف Excel:

1. الكمية المجرودة: 100 (من DB)
2. SAP وقت الجرد: 80 (من DB) ✅
3. الفرق المحسوب: 100 - 80 = +20 ✅
4. SAP الحالي (جلب مباشر): 85 ✅
5. الكمية النهائية: 85 + 20 = 105 ✅
```

---

### 📋 ملف Excel المصدر:

```
| ItemCode | CountedQty | SAP_AtCount | SAP_Current | Difference | UpdatedQty |
|----------|------------|-------------|-------------|------------|------------|
| ITEM001  | 100        | 80          | 85          | +20        | 105        |
```

**شرح الأعمدة:**

| العمود | القيمة | المصدر | الوصف |
|--------|--------|--------|-------|
| `CountedQty` | 100 | قاعدة البيانات | الكمية التي جردها الموظف |
| `SAP_AtCount` | 80 | قاعدة البيانات | الكمية في SAP **وقت الجرد** |
| `SAP_Current` | 85 | جلب حي من SAP | الكمية في SAP **وقت التصدير** |
| `Difference` | +20 | محسوب | الفرق = CountedQty - SAP_AtCount |
| `UpdatedQty` | 105 | محسوب | الكمية النهائية = SAP_Current + Difference |

---

## 🧮 المعادلة:

```javascript
الفرق = الكمية المجرودة - SAP وقت الجرد
الفرق = 100 - 80 = +20

الكمية النهائية = SAP الحالي + الفرق
الكمية النهائية = 85 + 20 = 105
```

---

## 💡 لماذا هذه الطريقة؟

### ✅ المزايا:

1. **احترام حركات SAP:**
   - إذا حدثت مبيعات/مشتريات بعد الجرد
   - يتم احتسابها في الكمية النهائية

2. **دقة عالية:**
   - نحافظ على الفرق الذي اكتشفه الموظف
   - ونطبقه على الوضع الحالي في SAP

3. **شفافية:**
   - نرى SAP وقت الجرد
   - نرى SAP الحالي
   - نرى الفرق بوضوح


## 🔄 سير العمل:

```
1. الموظف يجرد
   └─ يحفظ: الكمية + SAP وقت الجرد

2. النظام يعمل (مبيعات، مشتريات...)
   └─ SAP يتغير

3. المدير يصدر Excel
   ├─ يقرأ: الكمية المجرودة
   ├─ يقرأ: SAP وقت الجرد
   ├─ يحسب: الفرق = الجرد - SAP وقت الجرد
   ├─ يجلب: SAP الحالي (مباشر)
   └─ يحسب: الكمية النهائية = SAP الحالي + الفرق

4. المدير يحدث SAP
   └─ يستخدم عمود UpdatedQty
```
