## 🆕 الميزات الجديدة في V6

### 1. 📦 **نظام الوحدات المتعددة**

#### الأصناف المدعومة:
- **قطعة** / **قطعه** / **Piece** / **PCS**
- **باكيت** / **Packet** / **Pack**
- **سيت** / **Set**
- **درزن** / **Dozen**
- **كارتون** / **Carton**

#### واجهة الجرد الجديدة:
```
عند مسح باركود لصنف مدعوم، يظهر 3 حقول:

┌─────────────────────────────┐
│      إضافة كمية             │
├─────────────────────────────┤
│ قطعة:     [____]            │
│ درزن:     [____]            │
│   (1 درزن = 12 قطعة)        │
│ كارتون:   [____]            │
│   (1 كارتون = 144 قطعة)     │
│                              │
│ الإجمالي: XXX قطعة          │
│                              │
│     [إلغاء]    [حفظ]        │
└─────────────────────────────┘
```

#### الحساب التلقائي:
```
الإجمالي = قطعة + (درزن × 12) + (كارتون × 144)

مثال:
  قطعة: 5
  درزن: 2
  كارتون: 1
  
الإجمالي = 5 + (2 × 12) + (1 × 144)
         = 5 + 24 + 144
         = 173 قطعة ✓
```

### 2. 📊 **تحسينات التقارير**

#### أعمدة جديدة في Excel:
- `Qty_Pieces` - عدد القطع/الباكيت/السيت
- `Qty_Dozen` - عدد الدرزن
- `Qty_Carton` - عدد الكراتين
- `Qty_Total` - الإجمالي المحسوب

#### مثال على التقرير:
```
ItemCode | ItemName | UOM   | Qty_Pieces | Qty_Dozen | Qty_Carton | Qty_Total
---------|----------|-------|------------|-----------|------------|----------
PEN001   | قلم      | قطعة  | 5          | 2         | 1          | 173
PACK001  | دفتر     | باكيت | 3          | 1         | 0          | 15
OIL001   | زيت      | لتر   |            |           |            | 15
```

### Flutter Code:

```dart
// تحديد نوع الوحدة
String _getUnitType(String? uom) {
  final normalized = uom?.toLowerCase().trim();
  if (normalized == 'قطعة' || normalized == 'piece') return 'piece';
  if (normalized == 'باكيت' || normalized == 'packet') return 'packet';
  if (normalized == 'سيت' || normalized == 'set') return 'set';
  return 'default';
}

// حساب الإجمالي
double total = pieces + (dozen * 12) + (carton * 144);
```

## 🐛 استكشاف الأخطاء

### المشكلة: التطبيق لا يتصل بالسيرفر

**الحل:**
1. تأكد من تشغيل السيرفر: `node src/server.js`
2. تأكد من البورت الصحيح: `8020`
3. تأكد من IP الصحيح: `192.168.116.211`
4. تأكد أن الهاتف والكمبيوتر على نفس الشبكة

### المشكلة: لا تظهر حقول الوحدات المتعددة

**الحل:**
1. تأكد أن وحدة القياس (UOM) في قاعدة البيانات صحيحة
2. الوحدات المدعومة: قطعة، باكيت، سيت، درزن، كارتون
3. تأكد من كتابة الوحدة بشكل صحيح في جدول `barcodes`

### المشكلة: الحساب غير صحيح

**المعادلة:**
```
الإجمالي = قطعة + (درزن × 12) + (كارتون × 144)
```

**مثال للتحقق:**
- قطعة: 0، درزن: 1، كارتون: 0 = **12 ✓**
- قطعة: 0، درزن: 0، كارتون: 1 = **144 ✓**
- قطعة: 5، درزن: 2، كارتون: 1 = **173 ✓**
