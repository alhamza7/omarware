## 🧪 **اختبار سريع في Console:**

بعد فتح الصفحة، افتح Console (F12) ونفذ:

```javascript
fetch('/api/items/search?q=14145')
  .then(r => r.json())
  .then(d => {
    const item = d.items[0];
    console.log('البند:', item);
    console.log('وحدة القياس:', item?.uom);
    
    if (item?.uom) {
      alert('✅ SUCCESS: وحدة القياس = ' + item.uom);
    } else {
      alert('❌ وحدة القياس غير موجودة');
    }
  });
```

## 📋 **إذا لم تظهر بعد:**

### **1. تأكد من أنك في نافذة Incognito**
- لا تستخدم النافذة القديمة!
- افتح نافذة خاصة **جديدة**

### **2. افحص Network في Developer Tools**
```
1. اضغط F12
2. اذهب إلى Network
3. حدّث الصفحة
4. ابحث عن: app.js
5. تحقق من Response Headers:
   - يجب أن يكون Status: 200
   - تحقق من التاريخ (يجب أن يكون حديث)
```

### **3. تأكد من تشغيل السيرفر**
افتح Terminal جديد ونفذ:
```powershell
Get-Process | Where-Object {$_.ProcessName -eq 'node'}
```
يجب أن ترى عملية Node.js واحدة على الأقل
