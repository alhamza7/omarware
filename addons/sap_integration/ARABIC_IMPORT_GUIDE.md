# دليل استيراد البيانات من SAP - الإصدار المحسّن

## نظرة عامة

تم إصلاح جميع المشاكل في نظام الاستيراد من SAP وإضافة ميزات متقدمة جديدة.

---

## المشاكل التي تم حلها ✅

### 1. خطأ "import_record method not found"
**تم الإصلاح:** الآن يمكن استيراد العملاء والمنتجات بشكل صحيح.

### 2. الحد من الاستيراد إلى 20 سجل فقط  
**تم الإصلاح:** 
- الآن يمكن استيراد **جميع السجلات بدون حد**
- إذا كان الحد = 0 → سيتم استيراد جميع البيانات
- إذا كان الحد > 0 → سيتم استيراد العدد المحدد فقط

### 3. وحدات القياس بدون مجموعات أو تحويلات
**تم الإصلاح:** الآن يتم استيراد:
- **مجموعات وحدات القياس** من SAP
- **عوامل التحويل** بين الوحدات
- **العلاقات** بين الوحدات في نفس المجموعة

---

## الميزات الجديدة 🎉

### 1. استيراد بدون حدود
- اضبط "Customer Limit" = 0 لاستيراد **كل العملاء**
- اضبط "Product Limit" = 0 لاستيراد **كل المنتجات**
- الكيانات الأخرى تستورد كل السجلات تلقائياً

### 2. نظام الدفعات (Pagination)
- الاستيراد يتم على **دفعات** (100 سجل في كل دفعة افتراضياً)
- يمكنك تغيير حجم الدفعة حسب إمكانيات السيرفر
- كل دفعة يتم حفظها تلقائياً

### 3. مجموعات وحدات القياس مع التحويلات

#### أمثلة:

**مجموعة الوزن:**
- 1 كغم (الوحدة الأساسية)
- 0.5 كغم = نصف كيلو
- 500 غم = نصف كيلو  
- 250 غم = ربع كيلو

**مجموعة الدرزن:**
- 12 قطعة = 1 درزن

**مجموعات الكراتين:**
- كرتون صغير = 6 قطع
- كرتون متوسط = 12 قطعة
- كرتون كبير = 24 قطعة

**كل هذه المجموعات والتحويلات يتم جلبها من SAP تلقائياً!**

## كيفية الاستخدام 📝

### الخطوات الأساسية:

1. اذهب إلى: **SAP Integration > Import Data > Import Wizard**

2. اختر الـ Backend الخاص بـ SAP

3. حدد البيانات المطلوب استيرادها:
   - ✅ Import Customers (العملاء)
   - ✅ Import Products (المنتجات)
   - ✅ Import Units of Measure (وحدات القياس)
   - ✅ Import Warehouses (المستودعات)
   - ✅ Import Pricelists (قوائم الأسعار)
   - ✅ Import Sales Orders (طلبات المبيعات)
   - ✅ Import Quotations (عروض الأسعار)
   - ✅ Import Invoices (الفواتير)

4. اضبط الإعدادات:
   - **Customer Limit:** 0 (لجلب الكل) أو عدد محدد
   - **Product Limit:** 0 (لجلب الكل) أو عدد محدد
   - **Batch Size:** 100 (عدد السجلات في كل دفعة)

5. اضغط **Import Selected Data**

6. انتظر حتى ينتهي الاستيراد

7. راجع النتائج في تبويب **Import Results**

## ما يتم استيراده من SAP 📦

### وحدات القياس (UoM):
- **مجموعات** وحدات القياس
- **وحدات** القياس الفردية
- **عوامل التحويل** بين الوحدات
- **العلاقات** بين الوحدات في نفس المجموعة

**مثال واقعي:**
إذا كان عندك في SAP:
- مجموعة "وزن" تحتوي على: 1كغم، 0.5كغم، 500غم، 250غم
- كل هذه الوحدات ستُجلب مع التحويلات الصحيحة بينها

### العملاء:
- كل بيانات العميل
- العنوان
- معلومات الاتصال
- شروط الدفع

### المنتجات:
- كل بيانات المنتج
- الأسعار
- وحدات القياس المختلفة (مبيعات، شراء، مخزون)
- المجموعات

### الكيانات الأخرى:
- المستودعات (كل التفاصيل)
- قوائم الأسعار (كل الأسعار)
- طلبات المبيعات (مع البنود)
- عروض الأسعار (مع البنود)
- الفواتير (مع البنود)

## حل المشاكل 🔧

### لا يتم استيراد أي بيانات:

**تحقق من:**
1. الاتصال بـ SAP يعمل
2. المستخدم لديه صلاحيات القراءة في SAP
3. البيانات موجودة فعلاً في SAP
4. راجع السجلات للأخطاء المحددة

### استيراد جزئي (بعض السجلات فشلت):

**طبيعي:** بعض السجلات قد تفشل بسبب:
- بيانات ناقصة في SAP
- تنسيق غير صحيح
- قيود قاعدة البيانات

**الحل:** راجع السجلات التفصيلية وأصلح البيانات في SAP

### مشاكل في الذاكرة:

**الحل:**
- قلّل حجم الدفعة (Batch Size) إلى 50 أو 25
- استورد على دفعات أصغر
- زد ذاكرة السيرفر

### مشاكل في تحويلات وحدات القياس:

**تحقق:**
1. مجموعة وحدات القياس في SAP لها وحدة أساسية صحيحة
2. عوامل التحويل صحيحة
3. القيم ليست صفر

## ملاحظات مهمة ⚠️

1. **الاستيراد الأول قد يستغرق وقتاً طويلاً** حسب كمية البيانات
2. **لا تغلق المتصفح** أثناء الاستيراد
3. **يمكنك مراقبة التقدم** من السجلات
4. **الأخطاء الفردية لا توقف الاستيراد** - سيستمر مع البقية
5. **بعد الانتهاء** راجع تبويب Import Results للتفاصيل
