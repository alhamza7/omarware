# إعداد ULTRAMSG للواتساب

## الخطوة 1: إنشاء حساب ULTRAMSG

1. اذهب إلى: https://ultramsg.com
2. سجل حساب جديد
3. اربط رقم واتساب الخاص بك
4. احصل على:
   - **Instance ID** (مثل: instance12345)
   - **API Token** (مفتاح API الخاص بك)

## الخطوة 2: تفعيل ULTRAMSG في Odoo

1. اذهب إلى: **Point of Sale > WhatsApp > Configuration**
2. انقر **New**
3. املأ البيانات:
   - **Configuration Name**: ULTRAMSG
   - **Instance ID**: (الصقه من ULTRAMSG)
   - **API Token**: (الصقه من ULTRAMSG)
   - **API URL**: `https://api.ultramsg.com` (افتراضي)
   - **Phone Prefix**: `964` (للعراق)
4. احفظ

## الخطوة 3: إرسال رسالة تجريبية

### من واجهة Odoo:
1. افتح أي طلب محفوظ
2. انقر زر **Send WhatsApp** في الأعلى
3. سيتم إنشاء PDF وإرساله تلقائياً

### من شاشة POS:
1. افتح طلب محفوظ
2. انقر زر **WhatsApp** 📱
3. سيتم الإرسال فوراً

## تتبع الرسائل

### عرض جميع الرسائل:
**Point of Sale > WhatsApp > Messages Log**

### عرض رسائل طلب معين:
1. افتح الطلب
2. انقر زر **WhatsApp** في الأعلى (الزر الإحصائي)
3. سترى جميع الرسائل المرسلة لهذا الطلب

## تنسيق الأرقام

النظام يحول الأرقام تلقائياً:
- **الإدخال:** `07800114976`
- **المرسل:** `9647800114976` (مع رمز الدولة)

## حل المشاكل

### المشكلة: "ULTRAMSG not configured"
**الحل:** أنشئ إعداد جديد في: Point of Sale > WhatsApp > Configuration

### المشكلة: "Customer phone number is missing"
**الحل:** أضف رقم هاتف للعميل

### المشكلة: "Failed to send message"
**الحل:** 
1. تحقق من Instance ID و API Token
2. تحقق من رصيد ULTRAMSG
3. تحقق من اتصال الإنترنت
4. راجع السجلات في: WhatsApp > Messages Log
