# دليل التثبيت السريع - POS Perfume Custom

## 📦 التثبيت والتفعيل

### الخطوة 1: ترقية المودل
```bash
cd L:\Lugal-ai
python odoo-bin -u pos_perfume_custom -d your_database --stop-after-init
```

### الخطوة 2: إعادة تشغيل Odoo
```bash
python odoo-bin -c odoo.conf
```

1. افتح المتصفح: http://localhost:8069
2. سجل الدخول
3. اذهب إلى **التطبيقات**
4. ابحث عن "POS Perfume"
5. تأكد أنه مثبت ✅

## 🎯 الوصول إلى النظام

### الطريقة 1: من قائمة نقاط البيع
1. افتح **Point of Sale**
2. اضغط على زر **🌸 Perfume Interface**
3. ستفتح واجهة العطور الجديدة

### الطريقة 2: من القائمة الرئيسية
1. اذهب إلى **POS Perfume**
2. اختر **Orders**
3. اضغط **Create** لطلب جديد

---

## ⚙️ الإعدادات المطلوبة

### 1. إضافة منتجات العطور

**الطريقة:**
```
POS Perfume → Products → Create
```

**املأ الحقول:**
- **Name**: اسم المنتج بالإنجليزية (مثل: Vanilla Absolute)
- **الاسم العربي**: اسم المنتج بالعربية (مثل: فانيليا مطلقة)
- **Sales Price**: السعر بالدولار (مثل: 45.00)
- **Product Code**: كود المنتج (مثل: PF001)
- **Can be Sold**: ✅ مفعل
- **Product Type**: Storable Product

**احفظ** ✅

### 2. إعداد المخازن

**الطريقة:**
```
POS Perfume → Configuration → Warehouses
```

**أنشئ/عدل المخازن:**
- WH1: Main Warehouse
- WH2: Secondary Warehouse  
- WH3: Backup Warehouse

### 3. إضافة العملاء

**الطريقة:**
```
Contacts → Create
```

**املأ:**
- **Name**: اسم العميل
- **Phone**: رقم الهاتف (للواتساب)
- **Type**: Individual أو Company

## 🚀 البدء في إنشاء طلب

### خطوات سريعة:

1. **افتح واجهة العطور** 🌸
   
2. **اختر العميل** من القائمة المنسدلة في الأعلى

3. **ابحث عن المنتجات** في الجانب الأيمن:
   - اكتب اسم المنتج
   - أو كود المنتج
   - أو الاسم العربي

4. **أضف المنتج** بطريقتين:
   - اضغط مرتين على المنتج (Double Click)
   - أو اضغط Enter بعد البحث

5. **عدل التفاصيل** في الجدول:
   - الكمية
   - السعر
   - نسبة التخفيض
   - المخزن

6. **راجع المجاميع** في الأسفل:
   - المجموع الفرعي
   - التخفيض
   - المجموع الكلي (USD)
   - المجموع بالدينار (IQD)

7. **احفظ الطلب** باختيار:
   - **💾 Draft**: حفظ مسودة
   - **📋 Quotation**: إنشاء عرض سعر
   - **✅ Sale Order**: تأكيد طلب البيع
   - **📱 WhatsApp**: إرسال للعميل

## ⌨️ اختصارات الكيبورد

### في جدول الطلب:
- `Tab` → الانتقال للخانة التالية
- `Enter` → الانتقال للأسفل
- `Arrow Up/Down` → التنقل عمودياً

### في البحث:
- اكتب → بحث تلقائي
- `Arrow Down` → المنتج التالي
- `Arrow Up` → المنتج السابق
- `Enter` → إضافة المنتج للطلب

## 🔧 حل المشاكل

### المنتجات لا تظهر
**الحل:**
1. تأكد أن "Can be Sold" مفعل
2. تأكد أن المنتج غير مؤرشف
3. امسح cache المتصفح (Ctrl+Shift+Delete)

### الحسابات خاطئة
**الحل:**
1. تحقق من نسبة التخفيض (0-100)
2. تأكد من أسعار الوحدة
3. راجع سعر الصرف (افتراضي: 1 USD = 1,300 IQD)

### لا يمكن حفظ الطلب
**الحل:**
1. تأكد من اختيار العميل
2. أضف منتج واحد على الأقل
3. تحقق من جميع الحقول المطلوبة

### الواجهة لا تظهر
**الحل:**
1. نظف assets:
   ```bash
   python odoo-bin -u pos_perfume_custom -d your_database --stop-after-init
   ```
2. امسح cache المتصفح
3. أعد تحميل الصفحة (Ctrl+F5)
