🧠 Lugal AI

Enterprise-Grade AI Control Layer for Odoo × Gemini

Lugal AI is a sophisticated AI integration module that brings Google Gemini's power directly into your Odoo environment with enterprise-grade security, permissions, and performance optimization.

🔐

Role-Based Access

Granular permissions for Admin, Employee, and Customer roles. Data security enforced at every layer.

⚡

Smart Caching

Intelligent response caching reduces API costs and improves response times dramatically.

📚

Question Indexing

Pre-indexed common questions for instant, consistent answers without hitting the API.

🔍

POS-Style Search

Beautiful, fast product search interface with AI-powered suggestions and insights.

💬

Chat Interface

Intuitive chat UI for natural language queries about sales, products, customers, and more.

🌐

Bilingual Support

Seamless Arabic/English support with automatic language detection.

📊

Analytics

Comprehensive conversation history, performance metrics, and user feedback tracking.

🔌

SAP Integration

Built-in support for SAP data synchronization for enterprise deployments.

🚀 Quick Start

  1. Install the module
  2. Go to Lugal AI → Configuration → Settings
  3. Enter your Google Gemini API key
  4. Test the connection
  5. Start chatting with Lugal AI → Chat
