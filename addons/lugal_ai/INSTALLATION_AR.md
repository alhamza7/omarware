# 🧠 Lugal AI - دليل التثبيت والاستخدام

## ✨ ما هو Lugal AI؟

**Lugal AI** هو نظام ذكاء اصطناعي متطور متكامل مع Odoo يستخدم Google Gemini لتوفير:
- 💬 محادثة ذكية بالعربية والإنجليزية
- 🔍 بحث متقدم عن المنتجات (مثل POS)
- 🔐 صلاحيات محكمة حسب الدور (أدمن/موظف/عميل)
- ⚡ تخزين مؤقت ذكي لتقليل التكاليف
- 📊 إحصائيات وتحليلات شاملة
- 🔌 تكامل تلقائي مع SAP

---

## 📋 المتطلبات

1. **Odoo 16** أو أحدث
2. **Python 3.8+**
3. **مفتاح API من Google Gemini** - احصل عليه من [هنا](https://makersuite.google.com/app/apikey)

---

## 🚀 خطوات التثبيت

### 1️⃣ تثبيت المكتبات المطلوبة

```bash
cd D:\capo_dev\Lugal-ai\addons\lugal_ai
pip install -r requirements.txt
```

أو مباشرة:
```bash
pip install google-generativeai
```

### 2️⃣ إعادة تشغيل Odoo

```bash
cd D:\capo_dev\Lugal-ai
.\venv\Scripts\python.exe odoo-bin -c odoo_simple.conf -d lugal
```

### 3️⃣ تثبيت الموديول

1. افتح Odoo: `http://localhost:8070`
2. اذهب إلى **التطبيقات**
3. اضغط **تحديث قائمة التطبيقات**
4. ابحث عن "Lugal AI"
5. اضغط **تثبيت**

### 4️⃣ الإعداد

#### الحصول على مفتاح Gemini API

1. اذهب إلى: https://makersuite.google.com/app/apikey
2. سجّل الدخول بحساب Google
3. اضغط **Create API Key**
4. انسخ المفتاح

#### إعداد Lugal AI

1. في Odoo، اذهب إلى: **Lugal AI → الإعدادات → Settings**
2. الصق مفتاح API في حقل **Gemini API Key**
3. اختر النموذج (نوصي بـ **Gemini 2.0 Flash** للسرعة)
4. اضبط الإعدادات:
   - **Temperature**: 0.3 (للدقة)
   - **Max Output Tokens**: 1000
   - **Cache Duration**: 24 ساعة
5. اضغط **Test Connection** للتأكد
6. احفظ

## 🎯 كيفية الاستخدام

### 💬 المحادثة (Chat)

1. اذهب إلى: **Lugal AI → Chat**
2. اسأل أي سؤال:
   - "ما هي أكثر المنتجات مبيعاً هذا الشهر؟"
   - "كم إجمالي المبيعات اليوم؟"
   - "هل المنتج ABC متوفر؟"
   - "من هم أفضل 5 عملاء؟"

### 🔍 البحث عن المنتجات (Product Search)

1. اذهب إلى: **Lugal AI → Product Search**
2. ابحث بـ:
   - الاسم أو الكود
   - سؤال طبيعي (مثل "عطور رجالية سعرها أقل من 50")
   - الفئة، السعر، التوفر

### 📊 عرض السجل

1. اذهب إلى: **Lugal AI → Conversations**
2. شاهد جميع المحادثات السابقة
3. راجع الأداء والإحصائيات

---

## 🔐 الصلاحيات (مُعدّة مسبقاً)

### 👔 الأدمن (Admin)
- وصول كامل لجميع البيانات
- المبيعات، المنتجات، العملاء، الموظفين
- التحليلات والتقارير

### 👤 الموظف (Employee)
- مبيعاته الشخصية فقط
- العملاء المخصصين له
- معلومات المنتجات

### 🛒 العميل (Customer)
- معلومات المنتجات فقط
- طلباته الشخصية
- **لا يمكنه رؤية بيانات داخلية**

يمكن تعديل الصلاحيات من: **Lugal AI → الإعدادات → Permissions**

---

## ⚙️ الإعدادات المتقدمة

### فهرسة الأسئلة (Question Index)

لإضافة أسئلة شائعة للإجابة السريعة:

1. اذهب إلى: **Lugal AI → الإعدادات → Question Index**
2. اضغط **إنشاء**
3. أدخل:
   - **Question Pattern**: النمط العام للسؤال
   - **Category**: التصنيف (منتج، مبيعات، إلخ)
   - **Answer Template**: نموذج الإجابة
4. احفظ

**مثال:**
```
Pattern: هل المنتج [اسم] متوفر؟
Category: product
Required Models: product.product
Required Fields: name,qty_available
```

### التخزين المؤقت (Cache)

التخزين المؤقت **مفعّل افتراضياً** ويوفر:
- تقليل التكاليف بنسبة 70-80%
- سرعة استجابة أعلى
- تقليل استهلاك Tokens

يمكن تعطيله أو تعديل مدته من: **الإعدادات → Features**

---

## 🔌 التكامل مع SAP

إذا كان لديك موديول `sap_integration` مثبت:
- **Lugal AI سيكتشفه تلقائياً**
- سيضيف بيانات SAP في الإجابات
- سيعرض أكواد SAP، المخزون، آخر مزامنة

لا حاجة لإعداد إضافي!

---

## 📈 نصائح الأداء

1. **فعّل التخزين المؤقت** (Cache): توفير 70% من التكاليف
2. **استخدم Question Index**: للأسئلة الشائعة
3. **اختر النموذج المناسب**:
   - `gemini-2.0-flash-exp`: سريع ورخيص ✅ (موصى به)
   - `gemini-1.5-pro`: قوي لكن بطيء
4. **اضبط Temperature**: أقل = أدق (0.3 موصى به للأعمال)

من: **Lugal AI → Conversations** (view كـ Graph/Pivot)

## 🐛 حل المشاكل

### "No active configuration found"
**الحل**: اذهب إلى الإعدادات وفعّل Configuration

### "API key invalid"
**الحل**: تأكد من مفتاح API من [Google AI Studio](https://makersuite.google.com/)

### "Access denied"
**الحل**: تحقق من صلاحيات المستخدم في الإعدادات → Permissions

### استجابة بطيئة
**الحل**: 
- فعّل Cache
- قلل `max_output_tokens`
- استخدم Gemini 2.0 Flash

### لا توجد إجابة أو إجابة خاطئة
**الحل**:
- تأكد من وجود بيانات في Odoo
- تحقق من الصلاحيات
- راجع System Prompt
