# 🚀 البدء السريع - طباعة ليبلات SAP

## خطوات سريعة للبدء

### 1️⃣ التثبيت
```bash
# أعد تشغيل Odoo
# ثم حدّث الموديول
```

### 2️⃣ الإعداد (5 دقائق)

1. **إنشاء أو تعديل قالب**
   - المخزون → Product Labels → Label Templates
   - تبويب "SAP Integration"
   - ✅ Enable SAP Mode
   - أدخل SAP API URL و API Key

2. **اختبار الاتصال**
   - افتح: المخزون → Product Labels → SAP Label Printer
   - امسح أي باركود اختبار

### 3️⃣ الاستخدام

```
افتح واجهة الطباعة → امسح الباركود → الطباعة تلقائية! ✅
```

---

## 🎯 الميزات الجديدة

### ✨ طباعة مستمرة من SAP
- مسح باركود → بحث في SAP → طباعة فورية
- بدون أي تدخل يدوي
- إحصائيات مباشرة

### 📊 بيانات من SAP
- اسم المنتج
- وحدة القياس
- السعر (اختياري)
- الكود (اختياري)

### 🎨 قوالب قابلة للتخصيص
- تصميم مرئي بالسحب والإفلات
- دعم الصور والخلفيات
- محاذاة واتجاه النص

## 🔌 متطلبات SAP API

**Endpoint**: `GET /api/product/lookup?barcode=XXX`

**Response**:
```json
{
  "success": true,
  "product_name": "اسم المنتج",
  "uom": "وحدة القياس",
  "barcode": "123456789",
  "price": 100.00,
  "code": "PRD-001"
}
```

## 🎬 فيديو توضيحي (الاستخدام)

```
1. افتح: المخزون → SAP Label Printer
2. استخدم قارئ الباركود
3. امسح → يطبع تلقائياً!
4. كرر للمنتج التالي
```

**⏱️ زمن الطباعة**: 1-2 ثانية فقط!
