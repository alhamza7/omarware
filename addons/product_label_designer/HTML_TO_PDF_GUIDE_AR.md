# طريقة HTML إلى PDF الجديدة 📸

## ✅ **الحل البديل الذكي!**

بما أن wkhtmltopdf يواجه مشاكل، أضفنا طريقة جديدة:
**HTML Screenshot → PDF**

---

## 🎯 **كيف تعمل:**

```
1. تُعرض الملصقات في HTML
2. يلتقط Odoo صورة من HTML
3. يحوّل الصورة إلى PDF
4. PDF جاهز!
```

**الميزة:** يحفظ التصميم **بالضبط** كما في Preview!

---

## 🚀 **الاستخدام:**

### الطريقة 1: HTML Screenshot (موصى به)

```
Quick Print:
1. اختر منتجات
2. Print Mode: ⦿ HTML Screenshot to PDF  ← الجديد!
3. Download PDF

→ سيأخذ صورة من HTML ويحولها لـ PDF
→ نفس النتيجة بالضبط!
```

---

### الطريقة 2: wkhtmltopdf العادية

```
Print Mode: ⦿ A4 Sheet (Multiple per page)
→ استخدام wkhtmltopdf القياسي
```

---

### الطريقة 3: فردي

```
Print Mode: ⦿ Single Labels (One per page)
→ ملصق واحد لكل صفحة
```

---

## 📋 **الخيارات الثلاثة:**

| الوضع | الطريقة | متى تستخدمه |
|-------|---------|-------------|
| **Single Labels** | wkhtmltopdf | طابعة حرارية |
| **A4 Sheet** | wkhtmltopdf | طابعة عادية |
| **HTML Screenshot** | HTML→Image→PDF | إذا PDF فارغ ⭐ |
