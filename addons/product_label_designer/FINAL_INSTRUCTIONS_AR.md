## 🚀 **الاستخدام (بعد Upgrade):**

### **الطريقة الموصى بها:**

```
1. http://localhost:8070
2. F5 (Reload)
3. Apps → Upgrade "Product Label Designer"
4. انتظر 30 ثانية

5. المخزون → Product Labels → Quick Print

6. في المعالج:
   - Add All Products (أو اختر يدوياً)
   - Template: قالبك
   - Print Mode: HTML Screenshot to PDF
   - Copies: 1

7. Preview in Browser
   → شاهد التصميم

8. إذا أعجبك:
   - في صفحة Preview: Ctrl+P
   - Save as PDF
   ✅ جاهز!
```
