- حقل جديد في المنتج

### 2. ✅ طباعة A4 Sheet
- عدة ملصقات في ورقة واحدة
- شبكة قابلة للتخصيص (2×4, 3×6, إلخ)
- توفير الورق

### 3. ✅ المصمم المرئي (Visual Designer)
- **Drag & Drop** تفاعلي
- سحب العناصر بالماوس
- اختصارات لوحة المفاتيح
- معاينة فورية
- حفظ تلقائي

### 4. ✅ QR Code
- رابط المنتج تلقائياً
- حجم قابل للتعديل
- موضع قابل للتحريك

### 5. ✅ رفع الصور من المصمم
- **رفع الخلفية**: مباشرة من المصمم
- **رفع الشعار**: مباشرة من المصمم
- **معاينة فورية**: تظهر الصورة مباشرة
- **حذف**: بزر واحد

### 6. ✅ تحكم كامل بالمواضع
- كل عنصر له موضع X, Y
- الشعار والQR لهم حجم قابل للتعديل
- دقة بالملليمتر

### 7. ✅ جودة عالية
- PDF بدقة 300 DPI
- دعم طابعات حرارية
- دعم طابعات عادية

## 🚀 التثبيت الآن:

### الطريقة 1: من الواجهة
```
1. أعد تشغيل Odoo أو F5
2. التطبيقات → تحديث القائمة
3. ابحث: "Product Label Designer"
4. Install/Upgrade
```

### الطريقة 2: سطر الأوامر
```bash
./odoo-bin -c odoo.conf -u product_label_designer -d your_db
```

---

## 📖 الاستخدام السريع:

### A. طباعة سريعة:
```
منتج → Print Label → اختر قالب → Print
```

### B. المصمم المرئي:
```
Label Templates → افتح قالب → Visual Designer → Open
```

### C. رفع الصور:
```
في المصمم:
- Upload Background: اختر صورة خلفية
- Upload Logo: اختر الشعار
- معاينة فورية!
```

### D. طباعة A4:
```
اختر منتجات → Print Labels → A4 Sheet → Print
```
