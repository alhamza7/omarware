# حل مشكلة A4 الآن! 🔧

## 🔴 **المشكلة:**

كل ملصق في صفحة منفردة رغم اختيار A4 Sheet.

---

## ✅ **السبب المحتمل:**

القالب "1" إعدادات A4 Layout = 1×1 (افتراضي)

---

## 🚀 **الحل السريع:**

### الخطوة 1: افتح القالب

```
المخزون → Product Labels → Label Templates → افتح "1"
```

### الخطوة 2: عدّل A4 Layout

```
اذهب إلى تبويب "A4 Layout"

غيّر:
- Labels per Row: من 1 إلى 2
- Labels per Column: من 4 إلى 4 (أو أكثر)
- Margin: 2mm

احفظ (Save)
```

### الخطوة 3: جرّب مرة أخرى

```
Select Products → اختر منتجات
Action → Print Labels
Print Mode: A4 Sheet
Print PDF

→ الآن سيطبع عدة ملصقات في صفحة واحدة!
```

---

## 📋 **إعدادات موصى بها:**

### للملصق 80×60mm:
```
Labels per Row: 2
Labels per Column: 4
Margin: 2mm
→ 8 ملصقات في الصفحة
```

### للملصق 70×50mm:
```
Labels per Row: 3
Labels per Column: 5
Margin: 2mm
→ 15 ملصق في الصفحة
```

### للملصق 50×30mm:
```
Labels per Row: 4
Labels per Column: 9
Margin: 2mm
→ 36 ملصق في الصفحة
```

---

## 🎯 **التحقق السريع:**

في القالب "1"، تأكد:
```
☑ Labels per Row ≠ 1      ← يجب أن يكون 2 أو أكثر
☑ Labels per Column ≠ 1   ← يجب أن يكون 4 أو أكثر
```

إذا كانا = 1:
→ هذا سبب المشكلة!
→ غيّرهما إلى 2 و 4

---

## ✅ **بعد التعديل:**

```
قبل (1×1):
- ملصق واحد في الصفحة
- 10 منتجات = 10 صفحات

بعد (2×4):
- 8 ملصقات في الصفحة
- 10 منتجات = 2 صفحة فقط!
```

---

**الآن: افتح القالب "1" → عدّل A4 Layout → احفظ!** 🚀
