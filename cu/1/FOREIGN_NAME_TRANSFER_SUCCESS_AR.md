## 🚀 الطريقة المستخدمة

تم استخدام **أسرع طريقة ممكنة** وهي:
- **SQL مباشر** بدون المرور عبر ORM
- **تحديث جماعي (Bulk Update)** بدلاً من تحديث كل منتج على حدة
- **استعلام واحد** فقط لنقل جميع البيانات

### الكود المستخدم:
```sql
UPDATE product_product pp
SET 
    foreign_name = spe.foreign_name,
    write_date = NOW(),
    write_uid = 2
FROM sap_product_extended spe
WHERE spe.product_id = pp.id
AND spe.foreign_name IS NOT NULL
AND spe.foreign_name != ''
```
