### نظام أولويات ذكي للتسعير

```
┌─────────────────────────────────────┐
│ 1️⃣  سعر محدد في Pricelist؟        │

              ↓
┌─────────────────────────────────────┐

│    └─ السعر × factor ✅            │

```

```
3. غيّر UoM إلى: 0.5 كيلو
   → السعر: $22.00 (من Pricelist مباشرة)

```

## 📖 أمثلة عملية

### مثال 1: السعر المحدد

```
المنتج: [ADF00005] المعشوق
UoM: 0.5 كيلو

الخطوات:
1. ✅ يبحث في Pricelist
2. ✅ يجد سعر محدد: $22.00
3. ✅ يستخدمه مباشرة

النتيجة: $22.00
```

### مثال 2: الحساب التلقائي

```
المنتج: [ADF00005] المعشوق
UoM: 5 كيلو (غير موجود في Pricelist)

الخطوات:
1. ❌ لا يوجد سعر محدد ل "5 كيلو"
2. ✅ يجد سعر الكيلو: $13.25
3. 🧮 يحسب: 13.25 × 5 = $66.25

النتيجة: $66.25 (محسوب تلقائياً)
```

## 🎓 كيف يعمل؟

### الكود الرئيسي

```python
# في product.pricelist._compute_price_rule

# 1. ابحث عن سعر محدد
specific_price = find_specific_uom_price(product, uom)

if specific_price:
    return specific_price  # ✅ استخدمه!

# 2. احسب من السعر الأساسي
base_price = find_base_uom_price(product)
ratio = target_uom.factor / base_uom.factor
return base_price * ratio  # 🧮 احسب
```

### الأولويات

```
1️⃣  Pricelist (أولوية عليا)
    ├─ سعر محدد للـ UoM المطلوب
    └─ استخدام مباشر

2️⃣  Calculation (أولوية متوسطة)
    ├─ سعر الوحدة الأساسية
    └─ حساب بالمعامل

3️⃣  list_price (ملاذ أخير)
    └─ إذا فشل كل شيء
```
