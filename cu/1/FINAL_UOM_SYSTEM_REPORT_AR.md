## 🎓 **المفاهيم المهمة:**

### **UoM Group:**
```
مجموعة من وحدات القياس المرتبطة
مثال: كغم، غرام، طن (كلها وزن)
```

### **SAP Entry:**
```
رقم فريد لكل UoM في SAP
يُستخدم للربط مع الأسعار
مثال: Entry 6 = كغم
```

### **Conversion Factor:**
```
معامل التحويل بين الوحدات
مثال: 1000 كغم = factor 1000
      (1 وحدة = 1000 كغم)
```

### **Group Link:**
```
الربط بين UoM والمجموعة
يضمن استخدام وحدات متوافقة
```
