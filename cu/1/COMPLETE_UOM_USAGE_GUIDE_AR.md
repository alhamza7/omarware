# 📦 **PART 1: كيف يرتبط UoM مع المنتجات**

## **A. عند استيراد منتج من SAP:**

### **ما يحدث تلقائياً:**

```python
1. يجلب بيانات المنتج من SAP:
   {
     "ItemCode": "ADF00001",
     "UoMGroupEntry": 9,              // ← رقم مجموعة الوحدات
     "InventoryUoMEntry": 6,          // ← وحدة المخزون
     "SalesUoMEntry": 6,              // ← وحدة البيع
     "PurchaseUoMEntry": 6,           // ← وحدة الشراء
     "ItemPrices": [...]
   }

2. النظام يربط تلقائياً:
   ✅ المنتج → UoM Group (Entry: 9 = فل بلاستك)
   ✅ uom_id → كغم (Entry: 6)
   ✅ كل الوحدات في Group متاحة للمنتج!

3. النتيجة:
   ✅ المنتج يمكن بيعه بأي وحدة من المجموعة:
      - كغم (الأساسية)
      - 50 غم
      - 100 غم
      - 0.5 كيلو
      - 25 كغم
      - 100 كغم
      - 500 كغم
      - 1000 كغم
```

### **في واجهة Odoo:**

```
عند فتح المنتج:
Inventory → Products → ADF00001

في التفاصيل:
┌─────────────────────────────┐
│ UoM: كغم                    │ ← الوحدة الأساسية
│ Alternative UoMs: (يدوي)    │ ← يمكن إضافة يدوياً
└─────────────────────────────┘

في Sales Order Line:
┌─────────────────────────────┐
│ Product: ADF00001           │
│ UoM: [قائمة منسدلة]         │ ← اختر أي وحدة!
│   - كغم                     │
│   - 50 غم                   │
│   - 100 غم                  │
│   - 0.5 كيلو                │
│   - 25 كغم                  │
│   - 100 كغم                 │
│   ... إلخ                   │
└─────────────────────────────┘
```

# 💰 **PART 2: كيف يرتبط UoM مع الأسعار**

## **A. عند استيراد الأسعار من SAP:**

### **ما يحدث تلقائياً:**

```python
من SAP:
{
  "ItemPrices": [{
    "PriceList": 1,
    "Price": 10.00,              // سعر الوحدة الأساسية (كغم)
    "UoMCode": "كغم",
    "UoMPrices": [                // ← الأسعار لكل وحدة!
      {
        "UoMEntry": 7,            // 50 غم
        "Price": 0.50,            // سعر مستقل
        "BaseQuantity": 0.05,
        "AlternateQuantity": 1.0
      },
      {
        "UoMEntry": 14,           // 100 كغم
        "Price": 950.00,          // سعر مستقل (خصم!)
        "BaseQuantity": 100.0,
        "AlternateQuantity": 1.0
      },
      {
        "UoMEntry": 16,           // 1000 كغم (طن)
        "Price": 9500.00,         // سعر مستقل
        "BaseQuantity": 1000.0,
        "AlternateQuantity": 1.0
      }
    ]
  }]
}

النظام ينشئ تلقائياً:
✅ product.pricelist.item لكل UoM
✅ مربوطة بـ UoMEntry
✅ كل وحدة لها سعرها المستقل
```

### **في واجهة Odoo:**

```
Sales → Configuration → Pricelists
→ SAP Price List 1

ستجد:
┌──────────────────────────────────────────┐
│ Product    │ UoM      │ Price            │
├────────────┼──────────┼──────────────────┤
│ ADF00001   │ كغم      │ 10.00 ريال      │
│ ADF00001   │ 50 غم    │ 0.50 ريال       │
│ ADF00001   │ 100 كغم  │ 950.00 ريال     │
│ ADF00001   │ 1000 كغم │ 9500.00 ريال    │
└──────────────────────────────────────────┘

كل سعر مستقل ومرتبط بـ UoM ✅
```

# 🛒 **PART 3: كيف يعمل في المبيعات**

## **A. في Sale Order:**

### **السيناريو:**

```
1. عميل يطلب: 5 × 100 كغم (منتج ADF00001)

2. في Sale Order Line:
   ┌──────────────────────────────┐
   │ Product: ADF00001            │
   │ Quantity: 5                  │
   │ UoM: 100 كغم ← اختيار يدوي  │
   │ Unit Price: 950.00 ريال      │ ← من pricelist تلقائياً!
   │ Subtotal: 4,750.00 ريال      │
   └──────────────────────────────┘

3. ما يحدث تلقائياً:
   ✅ السعر = 950 ريال (من pricelist لـ "100 كغم")
   ✅ الكمية بالوحدة الأساسية = 5 × 100 = 500 كغم
   ✅ المخزون سينقص 500 كغم
   ✅ الفاتورة تطبع: "5 × 100 كغم"
```

## **B. التحويل التلقائي:**

```
المخزون الحالي: 1200 كغم

يمكن عرضه:
✅ 1200 كغم
✅ 24000 × 50 غم (1200 / 0.05)
✅ 12 × 100 كغم (1200 / 100)
✅ 1.2 × 1000 كغم (1200 / 1000)

في Sale Order:
- عميل يطلب: 10 × 100 كغم
- النظام يتحقق: هل يوجد 1000 كغم؟
- الجواب: نعم! (1200 كغم متوفرة)
- ✅ يسمح بالبيع
```

# 🔄 **PART 4: كيف تستخدم الآن**

## **الطريقة 1: في Sales Order** (الأكثر استخداماً)

### **الخطوات:**

```
1. Sales → Quotations → Create

2. أضف منتج:
   Product: [اختر منتج]
   
3. غيّر الوحدة:
   UoM: [قائمة منسدلة]
   - كغم
   - 50 غم
   - 100 غم
   - 100 كغم
   ... إلخ

4. لاحظ:
   ✅ السعر يتغير تلقائياً!
   ✅ حسب pricelist
   ✅ لكل وحدة سعرها

5. احفظ → تأكيد
   ✅ المخزون يُحدّث بالوحدة الأساسية
   ✅ الفاتورة تطبع بالوحدة المختارة
```

---

## **الطريقة 2: في Point of Sale (POS)**

```
1. POS → New Session

2. اختر منتج

3. في التفاصيل:
   UoM: [قائمة]
   
4. السعر يتحدث تلقائياً ✅

5. Pay → Done
   ✅ المخزون محدث
   ✅ السعر الصحيح
```

---

## **الطريقة 3: في Inventory (المخزون)**

```
1. Inventory → Products → [منتج]

2. Update Quantity:
   Quantity: 500
   UoM: [اختر وحدة]
   
3. النظام يحول تلقائياً للوحدة الأساسية ✅
```

# ⚙️ **PART 5: الإعدادات والتخصيص**

## **A. إضافة UoM لمنتج يدوياً:**

```

   UoM: [الوحدة الأساسية]

   - Add a line

```

## **B. تعديل الأسعار لوحدة:**

```
1. Sales → Configuration → Pricelists

2. [اختر pricelist] → Price Rules

3. Add a line:
   - Product: [منتج]
   - UoM: [وحدة معينة]
   - Price: [السعر]
   
✅ السعر يُستخدم تلقائياً عند اختيار هذه الوحدة
```

# 📊 **ملخص الربط التلقائي:**
