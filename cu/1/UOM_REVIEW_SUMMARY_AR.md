## 🎓 كيف يعمل الحساب التلقائي؟

### المعادلة البسيطة

```
السعر النهائي = السعر الأساسي × نسبة التحويل
```

### مثال

```
المعطيات:
├─ سعر الكيلو: $13.25
└─ نسبة 0.5 كيلو: 0.5

الحساب:
سعر 0.5 كيلو = 13.25 × 0.5 = $6.63

بدلاً من:
سعر 0.5 كيلو = $22.00 ← خطأ!
```
