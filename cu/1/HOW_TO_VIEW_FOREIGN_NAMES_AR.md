# 📍 دليل عرض Foreign Names في Odoo

---

## 🎯 أين يمكنني رؤية الـ Foreign Names المنقولة؟

---

## 1️⃣ في واجهة Odoo Web

### 📱 **في قائمة المنتجات**

#### الطريقة الأولى - من Inventory:
```
🏠 القائمة الرئيسية
  └── 📦 Inventory (المخزون)
      └── 📋 Products (المنتجات)
          └── Products (المنتجات)
```

#### الطريقة الثانية - من Sales:
```
🏠 القائمة الرئيسية
  └── 💰 Sales (المبيعات)
      └── 📋 Products (المنتجات)
          └── Products (المنتجات)
```

#### الطريقة الثالثة - من POS:
```
🏠 القائمة الرئيسية
  └── 🛒 Point of Sale (نقطة البيع)
      └── 📋 Products (المنتجات)
          └── Products (المنتجات)
```

### 📝 **في صفحة المنتج نفسه**

1. افتح أي منتج من القائمة
2. ستجد حقل **Foreign Name** في التفاصيل الرئيسية
3. عادة يكون بجانب اسم المنتج أو في قسم "معلومات عامة"

## 3️⃣ من خلال Developer Mode (وضع المطور)

### 🔧 **للمستخدمين المتقدمين**

1. **تفعيل وضع المطور:**
   ```
   Settings (الإعدادات) → Activate the developer mode
   ```

2. **افتح أي منتج**

3. **انظر للحقول المخصصة:**
   - ستجد `foreign_name` في قائمة الحقول
   - يمكنك إضافته إلى العرض في القائمة

---

## 4️⃣ في نقطة البيع (POS)

### 🛒 **عند البيع**

عند إضافة منتج في POS:
- سيظهر Foreign Name في تفاصيل المنتج
- يمكن البحث بالـ Foreign Name مباشرة
- مفيد للموظفين الذين يعرفون الأسماء الأجنبية فقط

---

## 5️⃣ في التقارير والطباعة

### 📄 **في الفواتير والعروض**

إذا كنت تريد إظهار Foreign Name في:
- الفواتير
- عروض الأسعار
- تقارير المخزون

يمكن تخصيص القوالب لإظهار هذا الحقل.

## 🔍 كيفية البحث عن منتج معين

### في واجهة Odoo:
1. اذهب إلى قائمة المنتجات
2. استخدم صندوق البحث في الأعلى
3. يمكنك البحث بـ:
   - كود المنتج (مثال: ADF00001)
   - اسم المنتج
   - Foreign Name (مثال: CK1)

### باستخدام السكريبت:
```bash
python show_foreign_names.py
# اختر الخيار 3 للبحث بالكود
# أو الخيار 4 للبحث بالاسم الأجنبي
```

   # اختر "yes"

## 🆘 استكشاف الأخطاء

### ❓ **لا أرى Foreign Name في واجهة Odoo**

**الحل:**
1. تأكد من تفعيل وضع المطور
2. قم بإضافة الحقل إلى العرض:
   ```
   Settings → Technical → User Interface → Views
   ابحث عن: product.product.tree
   ```

### ❓ **بعض المنتجات ليس لديها Foreign Name**

**السبب:**
- المنتجات غير مربوطة بـ SAP
- أو لا تحتوي على Foreign Name في SAP الأصلي
- العدد: 4,133 منتج ليس لديهم Foreign Name
