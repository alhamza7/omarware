## ✨ التحسينات المضافة

### التحسين #1: Auto Calculate Wizard ⭐⭐⭐⭐⭐

#### الوصف
معالج (Wizard) لحساب أسعار جميع وحدات القياس تلقائياً بناءً على نسب التحويل.

#### المميزات

```
✅ حساب تلقائي 100%
   - بناءً على Factors الصحيحة
   - دقة رياضية كاملة
   - تقريب ذكي

✅ خيارات مرنة
   - اختيار Pricelist محدد
   - تطبيق على منتجات معينة أو الجميع
   - مصدر سعر قابل للتخصيص

✅ حماية من الأخطاء
   - Validation للمدخلات
   - حد أدنى للسعر
   - خيار الاستبدال أو الحفظ

✅ واجهة عربية/إنجليزية
   - دعم كامل للغة العربية
   - تعليمات واضحة
   - رسائل مفصّلة
```

#### الملفات المضافة

```
addons/uom_in_pricelist/wizard/
├── __init__.py
├── auto_calculate_uom_prices.py (310 سطر)
└── auto_calculate_uom_prices_views.xml (98 سطر)
```

#### كيفية الاستخدام

```
1. Sales → Configuration → Pricelists
2. اضغط "حساب أسعار UoM تلقائياً"
3. املأ النموذج:
   ├─ Pricelist: اختر القائمة
   ├─ Products: (اختياري)
   ├─ Base Price Source: مصدر السعر
   └─ Overwrite: هل تريد الاستبدال؟
4. اضغط "حساب الأسعار"
5. ✅ تم!
```

#### النتائج المتوقعة

```

- إدخال 18,673 سعر يدوياً
- وقت: ~156 ساعة
- أخطاء: متوقعة

بعد:
- حساب تلقائي
- وقت: ~5 دقائق
- أخطاء: 0%
```
