├─ تختار 5 كيلو → $66.25 ✅ (محسوب: 13.25 × 5)
└─ تختار 10 كيلو → $132.50 ✅ (محسوب: 13.25 × 10)

✅ الأسعار المتباينة → محفوظة كما هي

## 🧪 اختبر الآن!

### 1. افتح المتصفح
```
http://localhost:8069
```

### 2. حدّث الصفحة
```
اضغط: Ctrl + F5
(تحديث قوي لمسح cache المتصفح)
```

### 3. افتح Sales Order
```
Sales → Orders → Create
```

### 4. اختبر!
```
1. أضف منتج: المعشوق (أو أي منتج آخر)
2. لاحظ السعر الافتراضي
3. غيّر UoM إلى: 0.5 كيلو
   → السعر يتغير إلى: $22.00 ✅
4. غيّر UoM إلى: 5 كيلو
   → السعر يتغير إلى: $66.25 ✅
5. احفظ Order
   → يحفظ بدون أخطاء ✅
```
